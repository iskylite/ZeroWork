# V0.1.2 本地 zsh 与共用终端

> 仓库清理说明：历史原始图像、日志和快照已移除；相关证据链接统一指向脱敏状态摘要，不表示原始逐项材料仍保存在仓库。

## 1. 版本产出与前置依赖

本版本交付可实际启动、输入、显示、调整尺寸、退出和关闭的macOS本地zsh终端，并建立后续SSH共用的TerminalController/TerminalSurface。Local是首版静态连接插件，不能在视图内增加绕过宿主的`if local then spawn`分支。

前置为[V0.1.1基础](V0.1.1_FOUNDATION.md)的静态注册表、中性创建参数、SessionHandle/OperationKey、工作区/页签、设置事务与能力投影。公共颜色、字体角色、控件、动效、线程及通用事件失效规则统一引用[设计规范](DESIGN_STANDARDS.md)，本文件只规定终端和本机进程的专有规则。

本版本覆盖C2本地生命周期、T1共用终端的显示/基础输入/IME/选择/剪贴板/时间装饰，以及S2外观的主题库、字体、终端辅助显示和背景图片。搜索、普通历史候选、全部`@`语法及完整历史页由[V0.1.5终端与历史](V0.1.5_TERMINAL_HISTORY.md)交付；组与广播由[V0.1.6](V0.1.6_GROUPS_FORWARDING.md)交付；助手呈现、授权和调用由[V0.1.7](V0.1.7_AI_ASSISTANT.md)交付。本版本提供它们需要的稳定服务，不能用“后续版本”省略Local的终端正确性、外观设置或资源回执。

只读依据为及，较早的仅保历史取证。Local正常`444:179847`、home`444:180305`、启动中`444:180962`、最小窗`444:183948`、菜单`444:185078`、身份`444:186005`、退出`444:186785`、启动失败`444:187566`、关闭确认`444:188269`、拖入路径`444:191147`用于逐态追踪。图中的用户名、cwd、时间、PID和网格是数据示例，不是运行常量。

## 2. 范围与插件能力

首版只支持macOS，固定后端`/bin/zsh`，交互式登录启动参数为`-l -i`；不增加bash、其他操作系统或可配置shell选择。Local创建参数仅含初始cwd及终端默认值，无HostConfig、地址、端口、认证、route或连接测试。

| 能力 | 本版本契约 | UI后果 |
| --- | --- | --- |
| TerminalService | PTY读写、resize、输出、EOF、VT模式 | 与SSH使用同一终端控制器和视图 |
| Process/CwdService | shell/前台进程信息、exit/signal、已知或未知cwd | 本机身份、退出墓碑、关闭影响及复制目录 |
| SessionContextProvider | 原owner的有界纯文本行、cwd、身份、截断标记 | 后续助手读取共用终端数据，不抓屏猜文本 |
| Local ExecService | 独立本机进程、明确cwd、stdout/stderr/exit、取消/清理结果 | V0.1.7通过已授权调用使用；不模拟用户终端敲字 |
| 本机文件引用 | 宿主管理、限明确选择/附加和授权范围 | 打开Local终端不等于授予任意本机文件读取 |
| SSH网络能力 | 无Auth/Route/RTT/Forward/远端Transfer服务 | 不挂网络指标、跳板、SOCKS、远端传输摘要或SSH配置入口 |

操作可用性同时取决于插件声明、当前服务绑定、会话状态和用户授权；插件“已安装”不等于服务可调用。显式触发Local不支持的`@up/@dl/@socks`时按V0.1.5就地说明需要SSH，不忽略、不把本地文件当上传，也不寻找其他远端页签代办。侧栏仍展示保存的远端资产，其route数字不代表Local具有网络能力。

## 3. 逐入口UI与参数

### 3.1 创建、复制与空态

`+`菜单的布局、过滤、键盘及焦点契约归V0.1.1。选择“本地终端”直接创建并聚焦独立zsh页签，短名“本地 · zsh”，Tab图标统一为单色Apple标志，保14×14固定槽与现有主题前景色；按住Command的数字替换、松开/失焦恢复及其余页签几何均沿V0.1.1，不为图标启动探测进程；不进入连接向导或询问地址。首次无资产、无会话和关闭最后页签时本地入口仍可用，不强制应用启动即自动创建。

| 入口 | 具体行为 |
| --- | --- |
| 新建本地会话 | 解析用户home→冻结有效默认值→分配独立SessionHandle和创建operation→启动；每次新建是新进程 |
| 复制会话与目录 | 与V0.1.1的DuplicateSession为同一动作，无默认快捷键；捕获原Local已知cwd，目录未知说明后使用home，不复制进程、输出、未发送输入或旧审批 |
| 退出后的“新建本地会话” | 新进程、新SessionId；旧只读输出/历史保留，不能复活旧PTY或重放命令 |
| 启动失败“重试启动” | 原pane显示新attempt；只有旧attempt资源已释放才允许重试；旧回调不得挂到新进程 |
| 重命名、组、搜索、历史、导出 | 通过相应版本的控制器操作捕获owner；本版本不造第二套Local专用历史/输入实现 |

默认cwd为当前用户home。明确携带的cwd在创建前校验、复制并在子进程启动前切入；若目录消失、权限不足或无法切换，原pane显示具体启动错误，不静默换到另一个目录。prompt和`Last login`等文本只来自zsh真实输出；应用不伪造用户名、目录、命令回显或成功结果。

### 3.2 正常、紧凑与只读状态

工作区外壳由V0.1.1统一：最终外边距5pt、卡间8pt、顶栏36pt、底栏26pt。1440×900窗口主区为1430×812、位于(5,49)；860×480窗口主区为850×392、位于(5,49)。终端pane扣除实际可见侧栏及间距后填充剩余区域，不保留旧固定pane坐标。文字和命中尺寸不随窗口缩小等比缩放。

底栏显示本机/zsh、运行/退出、UTF-8、真实网格及已知cwd；状态入口独立固定112×26，不随224/48侧栏改变宽度；完整身份由同锚点浮卡承接。身份浮卡显示“本机 · macOS”“/bin/zsh”、真实会话ID与“交互式登录”。cwd未知显示未知；不得从prompt文字推断。全局传输管理器仍可访问其它owner的任务，本地身份区不借用它们的摘要。

启动慢时原pane呈现“正在启动 zsh”，成功后清除启动占位并接入真实输出。启动失败保留可读原因、检查提示和重试，不画SSH逐跳进度。退出固定38px墓碑位于原pane顶部，显示exit或signal/原因、只读说明和新建入口；保留输出、复制、搜索、历史，不再有可写caret或输入行高亮。正常退出不是网络故障，不安排重连。

Local页签菜单宽284，条目为新建本地会话、复制会话与目录、重命名、加入终端组、当前会话历史、搜索终端、导出记录、关闭本地会话；依版本与服务实际状态挂载。“复制会话与目录”无默认快捷键，三主题均不显示旧⌘D；⌘D只属于垂直分栏，菜单/设置/帮助由V0.1.1同一action目录投影。菜单不能出现编辑SSH资产、认证、通信链路或SOCKS。原型菜单296px高为现有条目样例；隐藏不可用版本入口后按内容收紧，不留空行。

### 3.3 终端专有几何与时间装饰

以下x/y均相对直接父级，不能把画板canvas位置用作窗口位置：

| 对象 | 精确规则 |
| --- | --- |
| 行容器 | 位于终端内容面内x8，宽`contentWidth−16`，首行y8；每个VT视觉行高22，无行间分隔线 |
| 时间戳 | 行内`(12,4,48,14)`，JetBrains Mono9.5/14、右对齐、`fg-2`；显示完整`HH:mm:ss` |
| 正文 | 行内`(68,0,rowWidth−68,22)`，JetBrains Mono14/22；时间右缘60到正文68相隔8 |
| 换算 | 相对终端内容面，时间x20、正文x76；正文可用宽`contentWidth−84`，另扣实际占位滚动条 |
| 关闭时间列 | 正文回到内容面x8、宽`contentWidth−16`，不保留整列空位 |
| 输入行底 | `accent-06`覆盖行容器全部宽度，包括时间槽；无前缘竖条；只装饰当前可输入行 |
| 文本选区 | 仅VT正文；排除时间戳、chip、提示、墓碑和其它装饰 |

有固定身份头或横幅时，终端内容面从其底部开始，首行再下移8；不能覆盖身份或错误。续行、空输出行和当前输入在同一正文起点，缺metadata只留空时间槽，不让该行正文左跳。未来未渲染空白不生成行或时间。历史页复用这套终端内容面规则，外部时间轴的12px内距另由V0.1.5规定。

默认正文14px、视觉行高22px是用户确认的实现目标，设置默认倍率为`22/14=11/7`；显示可约1.5714，配置和计算保精度，不能反复将显示舍入值1.57写回。Figma设置旧1.5是只读待同步标注，不能作为当前21px默认。绝对像素行高转换为Zenit倍率时分别用`22/14`和时间`14/9.5`，不把22直接填入倍率属性。

已产生逻辑行的时间戳在对应输出/提交事件时固定，soft-wrap重排沿用该逻辑行metadata；当前可写且活跃输入行每秒刷新显示时间，提交后固定，失焦/切页签/只读/退出后停止该deadline。时间使用wall-clock及用户本地时区；耗时、排序与deadline用monotonic/sequence，不能把单调毫秒格式化成一天中的时间。时间不进入VT、复制、搜索或AI命令文本。

实时原型Local同一行存在`555:397022`和`556:399527`等同位可见时间戳。它们是重复装饰缺陷，运行时每条逻辑行只有一份metadata、每个视觉行只绘一份对应时间；不能复刻叠字或生成重复记录。本轮保留Figma只读。

### 3.4 底栏只读指标与可操作详情

2026-10-24 用户裁决：编码、终端网格、延迟仅显示只读值，不提供点击/悬停详情，不进入“更多状态”的二级详情。三主题的 `status_rtt`、`status_size`、`status_encoding` 和只含这些入口的 `status_overflow` 原型已移除。连接状态与链路详情继续按已确认的 V3 富信息浮层呈现，其中判断连接所需的端点、状态和 RTT 保留。

底栏数据仍来自当前 owner 的真实快照：编码仅显示已支持的 UTF-8；网格读最后已应用的 TerminalSnapshot 网格，未知时显示未知；RTT 仅实际 SSH 能力可用，没有测量显示未测量或未知，不把 Local 进程耗时当 RTT，不将逐跳 RTT 直接相加，也不因展示指标发探测命令。

归档身份 `status_readonly` 保留只读回放、搜索/复制可用、输入/执行停用及历史/导出动作。两动作消费原记录，不向原实时 Session 发送输入，不因查看归档身份激活同名实时连接。

窄窗“更多状态”仅保留必要可操作项目；当前样例只保留全局主题操作，面板按内容收紧为 360×84。全局主题进入同一全局选择，不新增会话主题或重复作用域说明。浮层位置根据实际触发锚点及窗口边界计算，不能照抄样例坐标。

底栏状态入口独立112宽，不对齐侧栏，指标26高、普通间距6。中间弹性空白先收缩，禁止工具覆盖或压缩字形。空间不足时可收起编码、网格等次要只读指标；独立全局主题可收入更多。身份、必要操作和实际活动的所属任务/转发/广播状态优先可达，不为保留未活动图标挤掉真实状态；Local不保留假网络空槽。

`StatusProjection`由控制器统一派生`owner/ownerKind/sourceRevision/identity/encoding/grid/geometryRevision/readOnly/cwd?/availability/rtt?`；`StatusPopoverState`保存`kind/owner/sourceRevision/anchor/focusReturn`。点击或Enter/Space先捕获原owner；更多中的可操作项目沿用该owner，不能在关闭首卡后重取active tab。同一底栏一次只开一张详情；再次触发同项关闭，切换同owner项目替换卡内容，Esc/外点/关闭回原按钮。切pane/tab使旧卡关闭，触发按钮因窄窗移入更多时更新anchor，owner失效则只关闭/清理，不转挂新会话或抢新pane焦点。

值刷新仍须匹配owner和revision；resize只更新已应用网格/anchor，不触发一次新的PTY操作；采样失败保可读原因和未知值。历史消费时禁用输入/执行来自HistoryState本身，不能仅凭浮卡里的“只读”文案判断。Local身份/网格/编码/更多按Local能力呈现；历史与导出在V0.1.5交付后接通，网络指标在V0.1.3交付后接通，均不得成为V0.1.2基本终端运行前置。

## 4. 共用终端控制链与输入

### 4.1 VT、绘制与resize

生产使用当前vendored `libghostty-vt` C ABI与同一个适配器；不新增较弱Local控制台，不恢复未接通的libvterm生产切换。PTY/SSH输出均按顺序立即feed VT，不用输入限速模拟平滑；显示端可合并中间快照，但保留最后版本、模式与终态。重编vendored VT库使用当前构建所需ReleaseFast，基础构建/测试与打包入口见V0.1.8§7，当前工程平台约束见设计规范§1。

共享快照至少保留屏幕/scrollback行身份、逻辑行/视觉行映射、VT列宽、完整字素、字符属性、tagged default/ANSI/indexed/RGB前景与背景、caret、终端模式、damage/style版本、OSC7/133事件。显式黑/白不能与default色相撞，行尾有背景的空格不能被无条件裁掉；纯颜色/样式变化也必须触发更新。状态词chip是旁路装饰，不能删除原始状态词再依赖chip补齐复制内容。

行节点池按真实可见行数及必要缓存维护，空视觉行保占位，不能硬编码“最多60行”。未变的文字和样式行不重复整形/布局；大scrollback按稳定行ID读取，不能为每次输出重建整份历史UI。终端使用公开DrawContext/DisplayItem或公共文本节点；绘制叶与命中/焦点/可访问性节点组合，不能另建平行AppKit/WebView终端。

resize使用最终正文宽及真实等宽cell advance计算完整列/行，至少1；同一轮更新VT网格、PTY winsize、caret、选区、gutter、鼠标坐标和IME候选框。输入只发给匹配generation的transport。连续resize可合并过期请求，但最后尺寸必须送达；reflow由VT负责，UI不额外折行或缩字。新的有效快照就绪前保旧帧，避免文字/光标分别换坐标造成闪烁。

字体通过实际FontRegistry/FontSelector解析，测量与绘制使用同一字体/字重/fallback。不得以`fontSize×0.6`猜列宽，不能只开`use_monospace_font`便宣称选中了JetBrains Mono。CJK双列、组合字符、emoji与替代字形保持VT列语义，应用绘制/复制/IME不切半个字素。

### 4.2 基础键盘、IME与终端模式

原生IME编辑客户端必须使用VT caret到UTF范围的映射提供preedit、选区、`frame_for_range`和取词几何；preedit是本机装饰，不提前写进PTY或历史命令库。组字Enter/Esc/方向键先由IME消费，提交字符串只编码/发送一次。终端滚动、resize、字体或时间列变化后重新投影候选框，不能把preedit固定加到行尾。

在尚未接入V0.1.5增强路由，或prompt上下文不可信时，基础VT输入仍完整可用；仅候选、应用指令和安全草稿替换停用，不能把可信行集成当成本版本zsh基本可输入的前置。普通Tab/Shift-Tab、Control组合、TUI键盘、application cursor/keypad按实际VT模式编码送终端。解析器产生的终端回复经过同一transport写入执行者，不能由parser直接抢写或让原SPSC变多生产者。alternate-screen与鼠标报告来自真实VT模式；应用明确保留的右/中键及Option选区按下表处理，其余鼠标事件按模式送TUI。

可信输入、辅助候选、`@`分支及完整单事件优先级唯一归V0.1.5；本版本提供焦点、IME、prompt/command边界、光标与模式信息，不靠屏幕出现`$`/`%`猜“现在可以替换命令”。

Local终端接收本地文件/目录拖入时，选择器或drop开始即捕获SessionHandle/generation和原输入目标；将每条真实路径按zsh语法正确引用/转义后插入当前输入，保留可编辑，不追加换行、不执行、不上传。空格、引号、反斜杠、换行等路径字符不能成为额外shell命令。目标退出、失效或焦点已转移时不改写新目标；按实际VT输入/粘贴边界派发，不依赖V0.1.5本地草稿替换。

### 4.3 选区、滚动、鼠标与粘贴

**2026-10-18用户实机反馈裁决**：采用非空拖选松开自动复制、右键始终粘贴；本节及下列逐态用例以该反馈为准，优先于旧原型中按选区切换右键行为的说明。

| 事件 | 唯一行为 |
| --- | --- |
| 主键拖选 | 普通线性文本选择；捕获pointer直到松开，非空选区在松开时自动复制；失焦/取消释放捕获 |
| Option＋拖选 | 按VT列做矩形选择，非零宽选区在松开时自动复制；菜单中的手势项只提示操作，不进入持续矩形模式 |
| 右键终端 | 始终请求粘贴，不因已有选区改为复制；单行只插入、无回车，不自动执行；多行按下述确认；不同时弹菜单或发送鼠标报告 |
| 中键终端 | 在点击处打开280px终端菜单，捕获点下时owner；页签中键属于V0.1.1关闭请求 |
| ⌘C | 终端有选区则复制；无选区按原型发送Ctrl+C；聚焦普通编辑器时走该编辑器复制语义 |
| wheel/触控板 | 普通屏滚scrollback；alt-screen由VT模式决定；上翻保阅读锚，新输出不抢回底部 |

空点击或零宽矩形在松开后清空选区，不改剪贴板。真实anchor失效时清理选区；WorkerBusy保留anchors并提示重试，不自动复制/粘贴或误发Ctrl+C。

选区使用稳定逻辑行/列锚，统一内部端点区间，转换Ghostty包含端点与UI半开区间时显式转换；复制、绘制、回放三者不能差一格。线性复制按真实硬换行组合，soft-wrap不凭UI视觉行重复插换行；矩形按选中列逐行复制，排除gutter，宽字/组合字不截断，缺列按矩形语义补空格。环形覆盖使锚失效时明确收敛，不把新的同索引行当旧选区。

粘贴先校验UTF-8、1MiB字节上限及伪造bracketed-paste边界；拒绝情况保原输入，不能因有换行先进入确认而绕过注入检查。合法多行显示不可变文本及逐行发送影响，批准绑定原session/generation/inputRevision、VT粘贴模式和后续V0.1.6广播集合。取消、owner/模式/目标变化使批准失效。每个目标按自己的VT模式编码一次，尾部不加回车，不能把一次UI批准缓存为后续粘贴许可。

应用终端菜单承接AI、复制/粘贴、上传/下载、广播、全局主题、搜索、历史、矩形手势等入口；具体业务分别归所属版本。Local不挂远端传输/SOCKS，终端没有选区时复制禁用并说明，暂未交付功能不能伪装已执行。菜单动作消费事件、不再透传为Shell输入。

## 5. 实体、接口与事件

以下是目标接口契约，命名不表示当前源码已有同名可编译类型。通用ID、线程/队列和所有权规则归V0.1.1及设计规范，不在此复制。

| 对象/操作 | 字段、结果及不变量 |
| --- | --- |
| LocalSession | `owner, createOperation, attempt, ptyMasterFd, childPid, processSessionId, shellPgid, initialCwd, reportedCwd?, foregroundInfo?, exitStatus?, eofSeen, reaped, cleanupState`；本机句柄不暴露给UI |
| TerminalBinding | `owner, serviceBinding, inputSequence, outputSequence, geometryRevision, terminalModeRevision`；绑定更换后旧事件只清理自有资源 |
| TerminalService.write | `owner, inputSequence, bytes, modeRevision`；成功消费实际写入字节数；EAGAIN保留余量，不当EOF或失败 |
| TerminalService.resize | `owner, geometryRevision, cols, rows`；至少1，过期尺寸可合并，最终尺寸有应用结果 |
| TerminalSnapshot | `owner, version, styleVersion, geometryRevision, modes, cursor, visibleRows, scrollbackRange, rowMetadata`；不可变投影供UI读取 |
| Process/Cwd事件 | `starting/running/foreground_changed/cwd_changed/exited/eof/cleanup_completed/cleanup_unknown`；cwd来自可信OSC7或进程服务，不从prompt解析 |
| SessionContextProvider | `readLines(maxLines) → owned lines+identity+cwd?+truncated`；只含原输出，排除时间/高亮/状态卡；读取不改变执行目标 |
| LocalExecService | `start(callId, command, cwd?, limits) → execHandle`及stdout/stderr/exit/cancel结果；独立进程/进程组，不写交互PTY；权限与批准由V0.1.7校验 |
| StatusController | 消费本owner不可变终端/身份/能力快照，发布§3.4 StatusProjection；open/close/switchDetail只改变Overlay状态。后续History适配器提供记录身份与回放网格，不持有可写TerminalBinding |

PTY创建顺序为分配master/slave→建立进程session与控制终端→设置初始winsize与有效cwd→以argv启动`/bin/zsh -l -i`→父进程关闭不再拥有的slave→注册非阻塞IO→发布running及服务绑定。继承应用启动环境并设置有效TERM，保留本机locale；用户路径经cwd/argv传递，不拼进`/bin/sh -c`。部分失败逆序释放已取得资源，不能发布假running。

输出走PTY→共用VT→不可变快照，原始输出事件另向V0.1.5记录服务发布。EOF与wait/reap分开：先EOF仍要等直接子进程退出，先退出仍要收敛最后可读输出；最后一行不能因收到exit提前清空。纯记录失败只降级记录并报告，不撕正常终端进程。

## 6. 状态、错误与关闭恢复

`creating/starting → running → exited`，启动失败为`start_failed`；任意需释放状态进入`closing → closed/cleanup_unknown`。`exited`是保留可读墓碑，不能等同已删除页签。ready仅在服务可用且宿主完成工作区attached后成立。

| 状态或错误 | UI与后续 |
| --- | --- |
| PTY/cwd/exec初始化失败 | 原pane保具体阶段和可读错误；回执已释放才启用重试；不降级为网络连接 |
| 正常exit/signal | 38px墓碑，保最后输出/exit；禁止输入和本机exec；允许本地阅读/历史 |
| 单独关闭空闲shell | 无实际前台任务则正常关闭，不无条件确认；仍执行资源回收。作为组关闭成员时遵从V0.1.6已经核对的整组确认，不能由本条绕过组确认 |
| 前台任务/所属exec仍在 | 480px关闭确认，原型示例244高；显示本机/session/真实命令及PID/影响，取消默认焦点，取消后进程继续 |
| 清理未知 | 保原owner与可读原因，禁向其发新输入/exec或启动替代attempt；不把已关闭UI当进程已结束 |
| 重新打开 | 分配新进程、新session，旧审批和旧输入不能转移；新owner从默认UI状态开始 |

确认关闭后先门控本session新输入/exec并撤销相关待派发工作，再由Local插件核实该PTY的进程session、内核前台进程组和仍归属的子进程/组。展示PID不是kill目标，不能按当前active tab、进程名或用户任意PID发信号。

本版清理策略为对仍确认归属的前台组、shell组及所属后台组发HUP，同一组只发一次；等待2秒仍存活发TERM，再2秒仍存活发KILL。每次信号前复验归属，不能误杀PID重用或已经脱离本session的对象。独立Local exec使用自己的handle/进程组按相同归属原则取消，不把它和交互shell混为一组。撤销fd监听、关闭PTY、wait/reap直接子进程并释放缓冲后发布cleanup；无法核实的进程只报告unknown，不伪报“全部结束”。取消确认不发信号。重复close幂等，不能在worker仍使用对象时提前free。

后续混合组必须明确本机/远端接收者；V0.1.6广播默认关闭且新成员不自动加入。V0.1.7本机调用卡必须标明本机、cwd、完整命令和影响；只有获得当前能力和授权才调用Local exec，不能回退SSH或以新会话继承旧批准。

用户关闭包含Local的组tab时，由V0.1.6确认后关闭全部成员，Local仍经本节的真实PTY/进程归属与cleanup回执释放；关闭组view不是Local进程退出。组确认取消不得提前发Local信号、断开远端或移除组；成员状态变化、部分失败与unknown由V0.1.6组协调器聚合，不在Local视图另起“只关组布局”分支。此整组协议在V0.1.6交付，不成为V0.1.2单个Local基本输入/退出的前置。

slider与数值维护同一typed值；拖动、方向键/Home/End更新该值和本draft预览，数值Enter校验一次、Esc恢复最后有效值，NaN/Infinity/越界或垃圾保raw/错误，不偷偷clamp写盘。共享`blur_px`的独立default/focus/invalid标本`359:1538725/1538745/1538767`明确0–96整数，97与小数均保raw/错误并阻Save；`background.transparency`为另一字段，其当前全页根只规定0–100范围，不能把旧overlay_alpha的整数约束转嫁过来。启用且素材不可用阻Save；关闭后坏旧路径不阻其它合法设置保存，仍保路径供以后恢复。

`settings-material-preview` `356:1308126`可在专用草稿预览中把同一effectivePreview投影到APP/默认终端背景；它由draftId持有、明确为预览，不修改已提交ConfigSnapshot。其已有“恢复已保存材质预览”动作仅把本draft材质字段恢复为最新已提交材质、增加assetRevision并取消旧解码，保其它分类/字段的raw和dirty；不做整份Reset或回滚其它入口的已提交主题。“返回设置”沿同一draft、原分类/selection/scroll返回，不自动Save。关闭专用预览或Discard撤本draft预览、恢复最新已提交背景；Save成功才发布已提交APP/全部默认终端材质。预览88%/24px是示例，不能据此重新注册旧background_opacity。重读失败使用主题底并保可恢复错误，不能显示空白卡或影响终端连接。

**用户已确认以最新R24整页为准，退役未挂载的旧透明色/浓度控件**。`overlay_tint`及`overlay_alpha`不注册当前schema，不提供可达设置、原生色盘/Hex、浓度slider或RGB reset，不参与当前材质预览/保存/渲染，也不把旧浓度解释为图片透明度。六个旧独立标本`359:1538560/1538587/1538616/1538653/1538673/1538695`及其三主题变体共18个根仅保历史证据；其RGB/旧浓度校验文字不是当前新增需求。保节点、原文和hash便于追踪，原型同步时仅隐藏并标注历史退役，不能删除其它仍生效的blur/fit/九点/路径/事务标本。当前产品只沿本节的开启→选择/替换/移除→适配/对齐→图片透明度→模糊度闭环。归档身份与三主题hash见逐状态核验文件auxiliaryMaterialSpecimens，不再作为待决产品项。
