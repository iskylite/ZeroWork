# V0.5 · 笔记插件与内置 AI 知识库

状态：方案与 SVG 设计，待实施。日期：2026-11-11。设计编号不修改应用版本，不表示原生功能已实现。网页插件独立归属 [V0.6](V0.6_WEB_CONNECTION.md)，二者没有运行依赖。

视觉基准：[笔记界面契约](../UI_V4/notes/README.md)、[主界面 SVG](../UI_V4/notes/workspace.svg)。沿用 [V4 风格](../UI_V4/STYLE_GUIDE.md)，本次按用户指定交付可编辑 SVG，不增加 HTML 基准或修改现有原生代码。

## 1. 本版裁决与范围

1. 随应用内置一个 `notes` 笔记插件，使用现有插件注册、页签、内容 renderer 和生命周期。
2. 顶层目录就是独立知识库，知识库下面最多允许两级子目录。知识库、一级子目录、二级子目录都能直接放文档；二级子目录不能再建子目录。没有第三级子目录、标签体系、嵌套笔记或空间层级。
3. 每个知识库只有一个「允许 AI 读取」开关，默认关闭，覆盖该目录全部文档及图片。子目录和文档不再设置 AI 读取权限；文档自身可设为持久化「只读」，两者独立。
4. 仅 ZeroWork 内置助手使用知识库。使用直接宿主工具，不新增内置 MCP 配置、服务端、辅助进程、监听端口或外部客户端。
5. 正文只保存 Markdown 文本和导入的静态图片。采用单页原位 Markdown 编辑，图片可复制粘贴及通过文件选择导入。
6. 以仓库当前 Zenit 组件和已有平台接口组合实现，不引入 WebView、富文本框架、第三方 Markdown 引擎、SQLite、向量服务或新的系统桥接。
7. 本版不做同步协作、任意深度目录、Word/Excel/PPT/PDF、OCR、图片内容索引、公式/Mermaid、富文本剪贴板还原、AI 自动写入、自动提炼记忆或固定记忆注入。已有 Markdown 文本可以直接粘贴，批量目录导入、导出和版本历史 UI 不作为本版前置。
8. 保留标准「笔记」内容页；在任意连接会话中，以 ⌥⌘N 唤出右侧笔记浮窗，宽度按整个 App 逻辑宽度的 2/3 计算，高度限于连接内容区。浮窗与标准页共用文档、草稿和编辑租约。
9. 页面不可见或浮窗收起时立即暂停笔记视觉工作；再次显示时只更新变化的块和当前可见内容。渲染暂停是内部生命周期，不显示为文档「只读」，也不停止必要保存或 AI 查询。

依赖为 `build.zig.zon` 的 `vendor/zenit`，Zig 0.17。以下是源码能力检查，不是本功能的运行验收：

## 3. 插件与宿主接入

### 3.1 注册和入口

| 注册项 | 约定 |
| --- | --- |
| id / origin | `notes` / bundled；实施时检查冲突后冻结 |
| quick_create | 在现有页签「＋」菜单提供「笔记」，无连接表单、地址、凭据、测试连接 |
| session_factory | 创建真正的本地插件 controller 和 SessionHandle；只管理内容生命周期，不创建 PTY 或网络 transport |
| workspace_kind / renderer | `notes`；标准 mount/update/focus/unmount |
| 图标与标题 | 页签复用现有 notebook 图标，名称为「笔记」；文档与目录图标沿用 SFTP，见 §11 |
| 服务 | 只提供必要的本地文档服务，不声明 terminal/exec/SSH/file transfer 能力 |
| 应用数据 | 唯一 NotesStore 由应用组合层持有，视图关闭不会删除数据或关闭 AI 查询能力 |

每个窗口默认复用一个笔记页签和一个笔记浮窗。窗口内只有一个活动笔记呈现宿主：标准页与浮窗切换时交接同一 DocumentSession、选区、滚动锚点和撤销历史，不各自创建可写副本。浮窗不改变底层连接页签的 active 身份，不创建 PTY／网络会话，也不把正文附着到当前服务器。标准页入口继续走原插件内容槽。不同窗口可以浏览同一目录；同一文档只允许一个活动编辑租约，另一窗口提供「在编辑窗口中打开」，不强抢未保存草稿。

首次从连接页唤出浮窗时，惰性取得或创建本窗口笔记 controller 与合法 SessionHandle，按同一 renderer 挂载；没有标准笔记页签时不为浮窗额外插入可见页签。「在页签中打开」复用此身份，不能借用底层连接的 owner 或再次创建一个笔记编辑会话。最后一个呈现被销毁前遵守保存门禁，隐藏状态可继续由窗口笔记宿主持有。

唯一 NotesStore 还持有有界的 DocumentSession（正文草稿、选区／撤销所属对象、保存队列和导入票据），不把未提交数据仅放在视图 Scope。关闭笔记页签只关闭该视图，但真正销毁视图／窗口及应用退出前必须走 §5.2 的保存门禁。切到后台与收起浮窗不销毁 DocumentSession，可立即冻结视觉工作。标准生命周期状态只表示本地页面可用，不显示虚构的网络连接状态。

### 3.2 与内置助手的关系

既有会话／组助手通过宿主工具查询所有已开启 AI 读取的知识库，无须把笔记插件加入该会话组，也无须先打开笔记页签。笔记页签自己的助手沿已有真实 SessionHandle 归属工作，没有终端执行能力。

笔记工具由 `src/plugins/notes/ai_tools.zig` 提供实现，宿主薄适配加入 `src/ai/host_tool_catalog.zig`；复用 Host Invocation、结果预算、取消和 receipt。调用最终转入唯一 NotesStore。普通会话级插件 tools 不冒充跨会话目录权限；不为本功能新增通用 FeatureHost、MCP 层或插件 API 大版本。打开浮窗不改变原会话助手的 owner、不把当前笔记自动注入原会话；「只读」也不自动开启 AI 读取。

更新现有 `session_prompt.zig` 的能力文案：仅在目录中存在笔记工具时说明「可查询已开放的笔记目录」；该例外不扩大终端、连接、组成员或本地文件访问权。子智能体不因历史工具结果而绕过当前目录开关。

## 4. 知识库与两级子目录模型

```text
笔记
├── 工作笔记                    知识库（depth=0），可开启 AI 读取
│   ├── 环境约定.md             直接放在知识库中的文档
│   ├── 服务器运维              一级子目录（depth=1）
│   │   ├── 数据库备份.md       一级子目录内的文档
│   │   └── Nginx               二级子目录（depth=2），不能再建目录
│   │       └── 生产环境证书更新.md
│   └── 项目记录                一级子目录（depth=1）
│       └── 发布检查.md
└── 个人笔记                    另一个独立知识库，可保持关闭
    └── 工作备忘.md
```

深度只计算知识库以下的子目录：知识库 depth=0，直接子目录 depth=1，其子目录 depth=2，文档不增加目录层级。模型和服务共同拒绝 depth>2，不能只靠 UI 隐藏入口：

| 对象 | 最小字段 |
| --- | --- |
| Library | `id, name, ai_readable, access_revision, revision, folders[], deleted_at?` |
| Folder | `id, parent_id?, name, sort_order, deleted_at?`；存于所属 Library，parent_id=null 为一级子目录；非空父节点必须是同库一级子目录 |
| Note | `schema_version, id, library_id, folder_id?, title, body_md, read_only=false, revision, updated_at, deleted_at?` |
| Image | 由同库 `assets/<sha256>.<ext>` 标识，引用从 Markdown 解析；尺寸等可作为可重建缓存 |
| DocumentSession | NotesStore 持有的 note_id、base_revision、edit_generation、lease_epoch、草稿、导入票据及撤销归属；不作为 AI 数据源 |
| ViewState | window_id、presentation(tab/float)、当前库／文档、展开项、滚动锚点、正文选区、搜索与返回栈、render_generation；不拥有唯一草稿，不作为 AI 数据源 |

文档可在同库根部、一级子目录和二级子目录之间移动；通过「移动到」菜单完成，V0.5 不要求拖动排序或跨库搬移。目录同库移动必须校验目标不是自身／后代、父节点存在且未删除、移动后的整棵子树最大深度≤2；不能只检查被移动目录。已有二级子目录的一级子目录不能再塞入另一个一级子目录。

新建菜单：插件根级可新建知识库；知识库和一级子目录可新建文档或子目录；二级子目录只可新建文档。模型反序列化、新建和移动共用同一个深度／同库／无环校验，手工篡改数据不能绕过。

名称 trim 后非空，拒绝控制字符；名称不是磁盘路径。目录名最多80个 Unicode 字符、文档标题最多120个，编辑前与粘贴入口校验并给出明确错误，不依赖输入组件截断。知识库名称在插件内唯一，子目录名称在同库同一父目录内唯一；唯一性仅对未删除且祖先可见的对象生效。文档标题允许重名，通过目录路径区分。ID 使用项目现有稳定身份生成方式，重命名和同库移动不换 ID。

### 4.1 文档只读

文档工具栏提供唯一锁按钮：可编辑时显示开锁图标，Tooltip「设为只读」；只读时显示闭锁图标与「只读」，Tooltip「解除只读」。使用现有 `ui.icons.lock_open/lock`，不另画图标。只读是写入文档信封的持久状态，重启、切换页签／浮窗／窗口、恢复删除项都不自动解除；没有定时解锁、密码或 AI 解锁接口。

| 操作 | 规则 |
| --- | --- |
| 设为只读 | 先结束 IME；同一文档串行队列收敛已接收编辑，将当前完整草稿和 read_only=true 原子提交为一个新 revision。提交前显示「正在设为只读…」并暂停新编辑，失败恢复可编辑草稿并显示错误，不提前亮起闭锁状态 |
| 有未完成图片导入 | 提供「等待导入」「取消导入并设为只读」；取消只移除未完成占位，保存其余文字。不得丢弃已落地文字，也不得留下 pending URL |
| 另一窗口持有脏草稿 | 当前窗口不能覆盖或强制锁定；通过「在编辑窗口中打开」让持有者处理 |
| 只读允许 | 阅读、选中文本、复制、搜索、查看图片、来源跳转；「更多 → 查看源码」使用readonly Textarea，仍可复制全文；AI 是否可读仍只取决于知识库开关 |
| 只读禁止 | 改标题／正文／图片引用、粘贴、源码编辑、撤销／重做正文、移动和删除文档；会改变其路径或删除其内容的祖先目录重命名／移动／删除也被拒绝，告知受保护文档，不默默跳过部分条目 |
| 解除只读 | 仅用户点击锁按钮的显式命令；原子保存 read_only=false 成功后再恢复编辑。失败仍只读；锁状态不进入 Cmd+Z 的文字撤销栈 |

所有文档写命令和异步图片落地同时校验 `read_only`、实际编辑租约、base_revision 和 edit_generation；不能只禁用 UI。锁定后旧保存／粘贴／导入回执不得重新写入。目录 AI 开关和视图展开状态不是文档编辑，不受文档只读限制。其他窗口的临时只读租约状态与用户设置的 read_only 分开，不能显示一个可点的解锁按钮来抢租约。

## 5. 存储与保存

### 5.1 最小持久化

采用现有文件原子替换模式，不增加数据库：

```text
<现有应用数据根>/notes/
  libraries/<library-id>/
    library.json
    documents/<note-id>.json
    assets/<sha256>.png
    assets/<sha256>.jpg
```

`documents/<id>.json` 是单文档存储信封，`body_md` 是唯一 Markdown 正文；标题、所属子目录、正文和 revision 同一个文件原子提交。JSON 不是用户编辑格式，也不引入富文档格式。这样无需 `.md + metadata` 双文件事务，不把图片写入 Base64 正文。内存块树、摘要、检索文本、纹理都可丢弃重建。

图片链接使用普通相对形式 `![图片说明](assets/<hash>.png)`，**解析基准固定为所属知识库根目录**，不随子目录或文档移动改变。渲染与 AI 图片工具仅接受解析后落在同库 assets 内的已引用资源，拒绝绝对路径、`..`、符号链接逃逸和外部 URL 自动加载。

### 5.2 保存状态机

`clean → dirty → saving → clean`；失败回到 `dirty(error)`。停止输入约 500ms 后提交，切换文档、关页签和退出时要求 flush；这是设计初值，实施时依据实际体验调整。只对 landed text 保存，不把 IME preedit 作为正文。

| 离开方式 | 未完成保存／失败处理 |
| --- | --- |
| 切换文档、进入搜索／源码模式、销毁笔记页签 | 先 flush；失败取消这次导航／关闭，保持原文、选区和原宿主，顶部显示具体错误与「重试」。成功后才执行原动作 |
| 切换到其他连接页签、收起浮窗 | 立即让该呈现进入 hidden 并停止渲染；草稿仍属于 NotesStore 的 DocumentSession，保存／导入任务继续收尾。失败不自动打开隐藏浮窗、不渲染隐藏内容，使用现有通知入口提示「笔记保存失败」，可打开或重试；再次显示时呈现原草稿和错误 |
| 关闭窗口／退出 App | 等待所有相关 DocumentSession 保存；有失败则取消关闭／退出并显示失败文档和重试，允许用户回到编辑。没有隐式丢弃分支 |
| 导入未完成而要求销毁／切文档 | 等待，或明确取消导入后保存其余内容；未决前不销毁 controller |

重试复用最新草稿，成功后通知消失；收起不是保存成功，也不是丢弃草稿。崩溃重启保证最近一次成功提交版本完整；未提交草稿不承诺崩溃恢复，正常退出必须经过上述门禁。

保存队列串行处理同一文档，参数包含 `base_revision` 和 `edit_generation`；旧保存回执不能清除新草稿的 dirty 状态。先写同目录临时文件、完成必要同步、原子替换，再发布新 revision 和检索快照。错误保留草稿，重试复用当前草稿，不覆盖其他窗口的新版本。工具只读取最近成功保存版本。

子目录的删除标记在 library.json 一次提交，使其全部后代目录和文档立即不可见和不可检索；查询可见性需要检查整条至知识库的祖先链，不逐篇修改才能完成删除。知识库删除同理。文档单独删除在自身记录上标记。更多菜单提供「最近删除」简单列表和恢复，V0.5 不做自动过期、复杂版本历史或永久清空 UI。图片不做运行中自动垃圾回收，防止撤销或恢复后断图；随整库数据清理一并处理。

恢复在服务中重新校验父节点可见、同库、无环、深度和活跃名称唯一性。父目录已删除时先引导恢复父目录，再重新发起当前恢复；不自动移动到根部。同名冲突弹出「恢复目录」，明确冲突名称、原位置和可编辑的新名称，默认建议「原名（恢复）」并可递增，只有点击「恢复」才提交；不会覆盖现有目录。取消保持删除状态。批量恢复的冲突逐项处理，不部分成功后宣称全部成功；原 ID、正文和 read_only 保留。目录重命名、移动、删除、恢复时一并失效受影响后代的路径／可见性快照，不等文档正文发生变化才更新搜索结果。

目录与正文权限沿现有数据策略（目录仅用户访问，文件 0600）。接入现有数据清理范围；备份／导出全部应用数据时，在单一 NotesStore 暂停提交的短暂边界取得文件清单，复制已提交记录及引用图片，不能把临时文件当正式文档。

## 6. 单页实时编辑

### 6.1 数据与交互

正文始终是一份 `body_md`。阅读态按块增量布局。进入编辑后，整篇正文由同一个原生 Zenit Textarea 管理光标、选区、输入法和撤销。渲染样式与 Markdown 原文字节位置保持映射，复制和保存使用 Markdown 原文。

| 状态／事件 | 行为 |
| --- | --- |
| 浏览文档 | 挂载可见块。点击正文，按点击位置进入整篇编辑 |
| 输入 Markdown | 光标及选区锚点所在行保留语法标记，其余行收起支持的标记。输入法正在组合的行使用原生输入显示 |
| 连续编辑 | 鼠标和 Shift＋方向键可跨行及跨段选取。替换、剪切、粘贴和撤销覆盖同一选区 |
| 回车 | 续写列表和引用。任务项续写为未勾选。有序项递增，并顺延紧随其后的连续同级编号。带明确数字前缀的标题续写同级标题，例如 `## 1.9` → `## 1.10` |
| 结束列表或引用 | 空项再按回车退出，Shift＋Enter 直接换行。围栏代码内按原样换行 |
| 图片 | 编辑时显示替代文字，光标行显示可编辑引用。「更多 → 查看当前图片」或在图片行按 Cmd＋Enter 打开原图。导入完成后可在图片下继续输入，并用一次撤销移除插入的引用 |
| 阅读与源码 | Escape 结束编辑并回到阅读位置。阅读态按正文可用宽度显示图片。「更多 → 查看源码」保留整篇纯文本编辑入口 |

正文行高为 26 点，字号随宽度使用 15 或 14 点。整篇编辑区与正文左边界对齐，内容较长时在编辑区内滚动。

### 6.2 原生验证

在标准页与浮窗验证键入和查看、光标回到标记、撤销／重做、IME、长块、保存后重开以及隐藏恢复。正文同一位置只保留一份文本显示。宽窄窗口通过原生截图核对换行与边界。

## 7. 图片复制粘贴

1. 仅编辑区获得焦点且用户执行粘贴时探测剪贴板；优先识别图片或复制的图片文件，其次按纯文本粘贴，不全局监听。
2. 冻结 `note_id`、编辑代次、选区与导入 ticket，复用已有图片类型嗅探、解码和总预算。PNG/JPEG 直接处理，其他可由现有图片管线成功归一为 PNG 的格式接受，失败显示具体原因。动态图片按静态首帧处理，不承诺动画。
3. 在当前编辑块显示导入占位；完成后先原子保存 assets 文件，再将占位替换为同库相对链接，编辑态在原位置显示图片引用，阅读态在同一位置显示原图。内容哈希去重限定同库。
4. 异步完成只能更新原笔记的原 ticket。用户继续输入时以占位锚点定位；切换文档、删除占位或取消后，不往新的光标或新文档插图。
5. 占位不是正式资源：导入未完成时保持「正在导入」和未保存状态，不将 pending URL 作为最终正文提交；其余草稿留在 NotesStore 持有的原 DocumentSession。销毁／切文档时等待或取消导入后保存其余文字；收起浮窗只暂停视觉渲染，资源落盘可继续。不能显示「已保存」而图片仍未落盘。
6. 图片导入作为一次文档编辑可撤销；撤销删除引用但暂不删除资源。失败提供重试／移除，保留正文。当前模型不支持图片不影响用户在笔记中插图。

工具栏只保留「插入图片」与更多菜单等必要操作，不增加图片处理面板。正文图片保持资源原始尺寸，只在宽度超出正文可用区域时等比缩小；内容区域变宽不能将图片放大到原始尺寸以上。比例为 `min(1, content_width / natural_width)`，宽高使用同一比例；图片与正文左边缘对齐，点击用现有 Modal 查看。不允许外链图片在浏览笔记或检索时隐式联网。

## 8. AI 读取开关与持久记忆

### 8.1 唯一授权入口

知识库「更多 → 目录设置」中配置名称和「允许 AI 读取」。默认关闭，两级子目录全部继承且无覆盖。开启时仅需该设置动作本身，无逐篇／逐次读取审批；界面常态只保留字段和开关，发送范围的必要信息通过开关的 Tooltip／可访问帮助说明「相关内容会发送给当前 AI 模型」，不常驻解释段落。

关闭时原子提交 `ai_readable=false` 并增加 `access_revision`，随后使未返回搜索、文档、图片任务及其缓存失效；每次派发和回传前都校验实际目录状态。先在有权目录中检索再排名截断，不能先全局找 Top K 再过滤。

不能收回已进入旧对话或已发送给模型的内容。关闭只阻止新的读取；后续上下文组装去掉独立的笔记检索缓存，旧聊天记录保留其真实历史。不开启 AI 的笔记即使正在当前页面编辑，也不会自动成为模型上下文。

此开关控制笔记插件向助手开放的能力，不是 macOS 文件加密或通用 shell 沙箱。笔记工具不返回内部磁盘路径，通用文件工具的应用数据路径守卫应拒绝绕过笔记服务读取；既有任意本地 shell 能力不因此变成新的隔离系统。提示词禁止以 shell 绕过关闭目录，不能宣称已经阻止同账户任意程序读取本地文件。用户主动复制正文发给助手属于另一次明确提供资料。

### 8.2 持久记忆行为

用户手写或粘贴的 Markdown 笔记就是持久资料。助手面对配置、约定、历史方案等问题，先查已开放目录；工具结果用于回答并附来源。新对话可以重新检索，不依赖此前聊天或上下文压缩摘要。

本版不自动写记忆、不默认注入所有笔记、不生成第二套摘要数据库。没有开放目录时不暴露可用笔记工具；没有相关结果时如实报告。无法保证模型每次都主动查，提示词与代表性问答验收覆盖调用行为，不能仅以「工具已注册」宣称持久记忆效果通过。

## 9. 四个内置只读工具

内部 ID 使用 `host.notes_*`，模型可见名称沿现有目录编码。参数与结果由同一模块定义，禁止把模型参数当权限。

| 工具 | 输入 | 返回 |
| --- | --- | --- |
| `host.notes_list` | 可选 `library_id, folder_id, cursor` | 无库 ID 时列已开放知识库；有库 ID 时列根部文档和一级子目录；有 folder_id 时仅列直接子项（一级子目录可返回二级子目录，二级子目录只返回文档） |
| `host.notes_search` | `query`，可选 `library_ids, folder_id, limit, cursor` | 按相关度排列的笔记片段、标题、路径、版本和来源引用 |
| `host.notes_read` | `note_id`，可选 `expected_revision, start_byte, max_bytes` | 已保存 Markdown、版本、原文范围、`next_byte`、可用图片引用 |
| `host.notes_read_image` | `note_id, expected_revision, asset_ref` | 该版本正文实际引用且同库授权的图片；复用现有图片结果通道及预算 |

默认 search limit=6，最大 20；read 默认 8KiB、最大 32KiB，整体结果仍遵守现有 host 64KiB 上限。分页边界按 UTF-8 字符完整对齐；非零 offset 必须附预期版本。图片不自动跟随全文返回，非视觉模型不提供图片读取工具。

搜索结果示例：

```json
{
  "note_id": "note-a1",
  "library_id": "library-work",
  "title": "生产环境证书更新",
  "path": ["工作笔记", "服务器运维", "Nginx"],
  "revision": 12,
  "start_byte": 96,
  "end_byte": 183,
  "excerpt": "更新证书后先检查配置，再重新加载服务。",
  "source_ref": "notes:library-work:note-a1:12:96:183"
}
```

`source_ref` 是稳定引用而非访问令牌。模型再次读取时逐次校验 AI 读取权限，已删除／撤权统一返回 Unavailable，不通过工具错误泄露关闭目录的标题。用户主动点击来源则走本地用户访问上下文：AI 开关关闭仍可在 UI 打开原笔记，但这次打开不向模型发送内容、不恢复 AI 权限。已删除向用户显示「笔记已删除」及「查看最近删除」，无权的模型仍只得到统一不可用。

用户打开来源时，若当前为连接会话就使用笔记浮窗，若已有标准笔记页前台就留在该页；保留原连接。切文档前通过保存门禁。版本不同提示「内容已更新」并定位到仍有效的标题或文档顶部，不伪造旧行精确命中，也不覆盖本地脏草稿；原文相同版本才使用字节范围。

错误分类保留 `Unavailable`、`RevisionChanged`、`InvalidArguments`、`ResultLimit`、`Cancelled`；不把读取失败包装成「没有相关笔记」。模型永远不能通过此接口创建、修改、删除或开启目录权限。

## 10. 本地搜索实现

V0.5 使用后台文本搜索，不引入分词器、数据库或向量依赖。内存保存已提交文档的标题、路径、可读文本和原文范围映射；内容变更后仅替换该文档快照。

- 中文按 Unicode 字符完整的字面子串搜索，「证书」「备份」这类双字词直接可查；英文支持 ASCII 大小写不敏感。首版不承诺拼音、简繁转换或语义同义召回。
- 查询支持空格分隔的多个关键词，默认同时匹配；引号作为普通字符处理，不接受 SQL、正则或查询 DSL。工具说明要求用简短主题词，必要时由助手换关键词再次查。
- 完整标题命中 > 标题包含 > 标题层级包含 > 正文命中；代码、图片 alt 和周围文字可查，图片像素不可查。
- 排名仅在当前授权集合内计算，按笔记去重，摘录保留上下文，不截断 UTF-8；没有异步语义索引，也没有「保存成功但关键词索引尚未完成」的独立状态。新保存快照发布与缓存失效在同一服务提交点完成。
- 搜索 worker 使用只读快照、取消 token、查询 generation 和 access revision；失效结果丢弃。UI 输入采用约 150ms 防抖，搜索不阻塞主线程。
- 验收数据集取 1,000 篇／约 10MiB Markdown，测量冷／热查询和取消，目标热查询 P95 < 200ms。该值是待测目标，超过时先优化缓存与扫描，不以本设计默认授权增加索引服务。

用户自己的搜索可以覆盖所有本地目录；AI 搜索只覆盖开启的目录，两者共享搜索实现但使用不同的服务端访问上下文。用户搜索结果不直接缓存成 AI 可见结果。

## 11. UI、空态和失败态

宽窗沿 V4：外留白12、全局侧栏238、工作区间隔24、内容起点y60。右侧目录宽252，高度与其笔记内容区一致，右边缘对齐；使用与左侧栏一致的轻表面，去掉目录自身投影。宽窗正文与目录使用 hstack，间隔16；展开目录占用布局槽，收起后正文恢复完整可用宽度。正文左右内距各48、宽度填满正文槽，不设760点上限；1440宽窗口下标准页目录展开／收起时正文分别为790／1058。笔记呈现可用宽度不足900时，目录改为边缘覆盖抽屉，正文内距24、不被挤成窄列，但覆盖态不允许继续在背后编辑，按 §11.1 收起目录后再恢复编辑。

图片在所有视口复用同一静态资源，原始尺寸为上限，超宽才等比缩小。示例拓扑源尺寸760×154，标准宽窗目录展开／收起均显示760×154，窄窗缩为544×110.232，宽浮窗目录收起时显示760×154，标题目录打开时缩为622×126.037；不能为窄窗重排图片内部卡片或文字。正文和代码块仍填满各自可用宽度，标准宽窗目录展开／收起时分别为790／1058。本例目录收起时图片已完整容纳，图片尺寸和下方段落位置保持；其他正文自然换行引起的布局变化照常处理。图片实际缩小时，后续块随图片新高度排布，不能因自动放大图片额外推移内容。字号不随整体画布缩放，长段落自然换行；显式阅读缩放与图片查看沿既有能力，不属于自动放大。

SVG 只出现实际产品控件、字段及笔记内容。不放设计解释、能力说明、副标题式导语、常驻操作教学或实现提示；这些全部放在本文和界面契约。已删除正文标题下的用途导语、插图重复标题／图注及权限浮层解释段落。

目录树行高 32，知识库／一级子目录／二级子目录／文档用每层 12 点缩进表达层级；文档和目录图标区分类型。目录更多操作只在 hover／focus 时出现。AI 开关只放目录设置，不在每篇文档上重复状态标签。详细尺寸、状态与 SVG 对照见[界面契约](../UI_V4/notes/README.md)。

文件／文件夹图标沿用 SFTP：目录使用 `ui.icons.folder` 与主题 accent；笔记在目录树及搜索结果中使用 `file_workspace_icons.asset("note.md")` 和对应类型色，依据 Markdown 内容类型选择，不因内部 JSON 存储信封变成 JSON 图标。SVG 直接复用项目现有矢量，选中态不重新着色文件类型图标。

### 11.1 右侧目录快捷键与焦点

采用 **⌥⌘B（Option+Command+B）**，只在前台标准笔记页或获得交互焦点的笔记浮窗内生效，编辑区与目录树均可切换；更高优先级模态框与 IME 先处理。默认 `⌘B` 控制左侧栏。用户自定义映射通过现有冲突检测。它是本应用的设计键位，不宣称系统统一快捷键或当前 App 已实现。

实现时新增 `notes_directory` 与 §11.3 的 `notes_float` 动作，接入配置默认值、序列化、录制、冲突检测和命令分发；当前 keybindings 的固定长度数组需要同步扩容，不能只写一个硬编码分支。按完整修饰键匹配；浮窗收起且标准笔记页不在前台时不派发目录动作。

目录通过普通 hstack／box 和已有 ScrollArea／VirtualList 组合，不使用 Popover 或模态 Sheet。宽窗并列侧栏中，正文可继续编辑、切文档不关闭目录。窄窗覆盖态中先按原生 IME 路径结束组合、暂存编辑位置并移走输入焦点；正文区域只承接「返回正文」点击，不把点击穿透成编辑／图片／链接操作。选择目录文档、点击正文或收起按钮后关闭覆盖目录，再恢复文档焦点及完整可见的光标；不会在被遮住的右半段继续输入。

Escape 优先级：IME → 子菜单／图片查看／目录设置／浮窗气泡 → 标准页窄窗目录覆盖 → 结束正文编辑 → 搜索返回层 → 笔记浮窗收起。搜索返回只在正文未处于编辑态时执行；宽窗目录仅在目录焦点内响应 Escape。每次只处理最内层，返回焦点对象已销毁时回到文档根；连接仍持焦时 Escape 继续属于连接，不凭浮窗存在就吞掉远程按键。窄窗编辑时出现目录覆盖的状态不成立。

初次进入按插件可用宽度决定默认状态（≥900展开，否则收起）；用户显式切换后，在本窗口笔记页签生命周期内记住状态，窗口缩放按900点内容宽度切换侧栏／边缘抽屉并更新布局，不覆盖手动选择。按钮 Tooltip 分别为「展开目录 ⌥⌘B」「收起目录 ⌥⌘B」，快捷键不常驻画布。

编辑快捷键保持 Cmd+V、Cmd+Z/Shift+Cmd+Z、Cmd+S；只读文档不派发修改动作。Cmd+F 在笔记内容持焦时搜索当前文档正文，连接持焦时仍搜索当前连接，不能因浮窗打开就重定向。源码模式、图片插入和锁定放工具栏／更多菜单，不增设易误触的锁定快捷键。

### 11.2 搜索进入与返回

搜索前保存当前文档；失败保留编辑页与错误。保存成功后记录来源宿主、note_id、正文选区和段落滚动锚点，展示单处查询输入、范围选择与结果列表。左上返回箭头 Tooltip「返回笔记」，空查询时最近文档不冒充搜索命中，零结果仍保留查询／范围与返回入口。Enter 打开选中结果，方向键只导航结果，Ctrl／终端键不被后台笔记消费。

打开结果后文档左上显示返回箭头，Tooltip「返回搜索结果」；点击或非编辑状态的 Escape 恢复 query、范围、选中结果和列表滚动位置。再从搜索页返回，恢复进入搜索前的笔记位置。查询取消、文档切换和过期结果都带 generation；已修改的结果文档仍要经过保存门禁才返回。范围包含全部本地知识库，不把用户结果传给 AI。

### 11.3 任意连接会话中的右侧浮窗

默认 **⌥⌘N（Option+Command+N）**：在本窗口任意连接会话／连接组内容中显示或收起笔记浮窗，包括 Local、SSH、SFTP、KVM，以及未来经同一宿主注册的内容 renderer；与连接在线／离线状态无关，不按协议名列白名单。已显示时再次按下收起。标准笔记页已在前台时仅聚焦该页，不再叠一个笔记副本。这是 App 内快捷键，不注册全系统热键。

页签「＋」菜单提供「笔记」标准页入口。会话内使用 ⌥⌘N 唤出或收起笔记浮窗。浮窗标题栏左侧显示「笔记」和面包屑。知识库与文件夹分别用书架和文件夹图标，悬停显示释义。点击面包屑或按 ⌥⌘B，在面包屑下方打开全部笔记目录树，选中文档后收起气泡。标题目录按钮打开浮窗右侧卡片，显示当前文档的 Markdown 标题，按级别缩进，点击一行跳转到对应标题。搜索复用终端的搜索气泡，只查当前文档正文。「查看源码」和「最近删除」直接显示在标题栏，编辑中的图片通过粘贴插入。收起 Tooltip 显示实际配置键位。首次唤出恢复本窗口最近文档，无文档则进入已有新建／空态。标准页也提供面包屑、文档标题目录和当前文档搜索。固定知识库时，点击面包屑在树中定位当前笔记。知识库收起时，面包屑下方打开目录树。「搜索笔记库」是标准页的独立入口，支持全部目录和当前目录。查找、编辑、图片、只读、目录设置与标准页共用组件和服务，不新增第二套笔记数据。

**尺寸以 App 窗口内容画布计算**：令 W 为包括全局左侧栏在内的 App 逻辑宽度，C 为当前连接内容区；`panel_width=min(2×W/3, C.width)`，右边缘=C.right，y=C.top，height=C.height。现有最小窗无需夹紧；额外夹紧只用于未来内容槽比2/3窗口更小的情况，不强加最小640宽覆盖用户比例。窗口系统边框／阴影不计入 W。当前样例为：

| App 视口 | 内容区 C | 浮窗 x/y/w/h | 内部目录 |
| --- | --- | --- | --- |
| 1440×900 | 274/60/1154/828 | 468/60/960/828 | 内部可用宽960，默认并列目录252；正文宽596 |
| 860×480 | 256/60/592/408 | 274.667/60/573.333/408 | 默认收起目录；正文宽525.333，目录展开时遵守覆盖态输入门禁 |

浮窗标题栏高52。目录树气泡宽300，按内容增高，高度上限352。标题目录卡片宽228，在浮窗右侧的正文区域内垂直居中。高度随标题数量增长，最高400点，且上下至少各留12点。宽窗时与正文并排，窄窗时覆盖在正文右侧。目录树和标题目录各自滚动。文档标题与 Markdown 正文左边缘对齐浮窗「笔记」文字。右侧面板使用现有 overlay 表面和轻边界／左侧阴影，圆角12，绘制与命中裁剪到 C；不遮盖顶层页签栏、全局工具或全局主机侧栏。不修改原连接的布局宽度、不重建或暂停 PTY／SFTP／KVM。面板外的连接内容继续可操作，点击外部不自动收起；点击面板空白不得穿透发送终端输入。与 AI 等已有非模态浮层使用同一激活顺序，模态框／portal 保持更高优先级；仅完全不可见的笔记视图进入渲染暂停，失焦但仍可见不等于隐藏。

「在页签中打开」创建或复用原标准笔记页签，转交同一文档、草稿、撤销、搜索返回栈与滚动位置，再隐藏浮窗；本窗口不会同时挂两份可写编辑器。用户主动选中已存在标准笔记页签时执行相同交接。切换其他连接会话时浮窗可保持显示，文档不随连接改变；关闭浮窗恢复当前有效连接的焦点，不盲目恢复已销毁的来源节点。浮窗内的文字、快捷键和粘贴都先由笔记处理，不能同时到达 PTY／KVM／网页；遵守已有连接失焦释放按键逻辑。

本次源码核对发现 `src/main.zig` 的现有新建连接分支仅判断 Command 与 N，未排除 Option／Shift。实施时必须先分发配置中的 notes_float，再将旧新建连接分支限定为精确 `⌘N`；同时测试用户重绑定后的剩余路径，不允许 ⌥⌘N 同时触发新建连接。模态框、快捷键录制与 IME 组合优先，组合中的快捷键不执行；不覆盖用户已自定义键位。

### 11.4 可见时增量渲染，隐藏时暂停

文档 read_only 是持久写保护；render 状态是每个呈现宿主的运行状态，二者没有自动联动。后台笔记仍可通过授权工具读取最新已保存内容，必要的保存、导入文件落盘和搜索快照发布可继续；不得把「不渲染」实现成停止业务提交。

| 呈现状态 | 允许的视觉工作 |
| --- | --- |
| 未打开 | 不创建正文节点或图片纹理 |
| visible-clean | 保留现有块／布局；无变化不请求重绘，光标仅在实际编辑且持焦时按既有组件节奏更新 |
| visible-dirty | 编辑态更新可见行；退出编辑时增量解析受影响的阅读块，复用未变化节点；优先当前视口及前后各一屏 |
| hidden | 非活动标准页、浮窗收起、最小化或宿主明确不可见后立即暂停：暂停正文更新，取消展示用图片解码任务和定时器，移走编辑焦点，停止笔记发起的 layout/paint/requestRedraw；只记录最新版本及合并脏区。用户已发起的图片导入验证／落盘是数据任务，可继续收尾 |
| resume | 先读当前权限、只读状态和保存错误，再比较缓存键；无变化直接复用，有变化只补差异；不回放隐藏期间每一次事件 |

可见性由宿主 active tab／浮窗显示状态和窗口可见状态显式通知。当前 RendererInstance 没有该通知，需新增默认空实现的可选 `presentation_changed` 接缝；`focus_changed(false)` 不能替代，因为点击仍可见的底层连接只会失焦。浮窗关闭命令一经接受即进入 hidden，没有收起退出动画；展开可用有限时长的横向出现过渡，减少动态效果时直接显示。

派生块表增加仅内存存在的 `block_key`，按内容、kind 和相邻锚点复用身份，字节范围随前文编辑平移；不能把 start_byte 直接当永久节点 ID。改变围栏、列表边界等结构时扩展到安全解析边界，不能只改当前一行。如果无法证明局部解析正确，可在 worker 对当前文档做一次完整解析，但主线程仍只更新不同块，不对整个 Markdown 控件重新绑定全文。

缓存键至少包含 note_id、正文/草稿代次、块内容哈希、可用宽度、字体、主题及图片资源哈希。宽度变化只重排受影响可见块，主题变化只更新相关样式；丢失字体／布局缓存可重新测量，不能承诺所有重开都是零布局。目录和搜索结果复用现有有界列表；长文档视图按可见块保留节点及占位高度，活动 Textarea 固定，不因块回收而失去 IME／撤销。活动 Textarea 复用 Markdown 行内解析器。

隐藏时只保留当前 DocumentSession 和至多一个最近呈现的可复用输入实例／轻量块缓存；图片纹理进入既有有界资源缓存并可逐出，不为每篇访问过的笔记永久保留 GPU 对象。大文档只保留元数据及必要脏草稿。恢复优先复用；被逐出的资源按可见范围懒加载。所有后台视觉结果带 `window_id, presentation_generation, note_id, edit_generation`，回传时隐藏／已切宿主／版本过期立即丢弃，不能通过旧回调唤醒隐藏界面。相同文档的草稿和撤销不通过 setText 重新灌入而清空；公开 API 无法安全保留时必须在 G0 报告具体缺口。

验收分别计数笔记自己的 parse／节点更新／图片解码／layout／重绘请求，排除底层正在输出的终端。隐藏10秒且收到多次文档更新时，笔记视觉计数不增加；保存可成功且 AI 读取最新提交。再次打开只处理最终差异，无修改且缓存有效时不重新解析／解码／重建。性能是待原生实测的门槛，SVG 不显示「增量中」「冻结中」或虚构性能数字。

## 12. 模块与最小改动面

建议新增 `src/plugins/notes/`，按实际规模组织 `plugin/controller/store/model/search/editor/view/styles/ai_tools/assets`；名称为职责，不要求机械建立同数文件。
