# 终端输入冲突仲裁（Terminal Input Conflict Arbitration）

## 背景

`host.run_in_terminal` 的 Preflight 在审批之前执行。当终端 surface 上存在宿主管线暂存输入时，Preflight 返回 `error.InputConflict`，此前直接走 `rejectedHostInvocation` 拒绝：模型收到 `rejected` 结果且无 `next_tool` 提示，既没有恢复路径也无法自察，形成架构死角。

与 `ShellPromptNotObserved` 已有的宿主自动恢复（`autoRecoverShell`，V0.7 §2.2）不同，输入冲突中有一部分内容属于**用户的未发送内容**（IME 组字、待确认粘贴），宿主无权静默丢弃，必须经用户仲裁。

## 分层恢复设计

Preflight 失败为 `InputConflict` 时（每次工具调用限一轮）：

| 层 | 触发条件 | 行为 |
| :-- | :-- | :-- |
| 0 | 任何未恢复的 InputConflict | 返回命令未发送与只读终端检查提示。 |
| 1 | worker 写队列未排空、待准备的粘贴、已确认的粘贴或受控协议编辑 | 不清理，不阻塞 UI；提示操作者等待正常处理并重新读取终端。 |
| 2 | 单独的 IME 草稿或尚未确认的粘贴 | 先冻结授权目标、终端 Surface 实例和草稿修订，弹出 composer 仲裁卡。确认后只清除该份仍未变化的草稿，然后重新走正常命令预检。 |

**安全不变量：**

1. 清理只处分用户刚明确确认的、尚未写入 PTY 的原草稿，不动普通队列、协议编辑或期间新增的输入。
2. 清理前重新验证派发栅栏、目标/服务、会话代次/成员、Shell、输入租约与草稿修订；变化即拒绝，不清理、不发命令。
3. 清理不会写终端字节或调用 Shell 自动接入。下一步重新走原有预检和命令审批。单次调用最多仲裁一轮。
4. 仲裁不经过自动放行策略；Stop、关闭、接力或新指令同步使待决项失效。

## 冲突分类与探测

`Surface.inputConflictKind()` 是宿主预检对终端本地输入暂存的统一识别。只有 `Surface.stagingDecision()` 提供独立、未确认的 IME 或粘贴快照时，才允许发起清理确认。UI 调度器只做当前状态检查，不等待 worker 队列排空。

## UI 通道

仲裁卡复用既有 composer interaction 视图（src/ui/ai_composer_interaction_view.zig）：

- `Ticket` 新增 `.conflict` 变体；`Snapshot` 新增可选 `accept_label`/`reject_label` 覆盖。
- 卡片在无审批/工具授权/问答挂起时才浮现（用户自己的决策优先）。
- 决策经 `composerInteractionAction` 主线程回调写回仲裁邮箱；批准 → 清理并重试，取消/`Esc` → 按原错误拒绝。
- worker 挂起前 `bridge.emitHostStep(.approval, "终端输入被占用，等待你处理")`，形成与审批一致的步骤事件审计。

## 已知边界（不在本方案覆盖内）

- 用户草稿**已送达 shell 行编辑器**（暂存已排空）的场景：`inputConflictKind()` 探测不到，属 shell 集成层行内容 fence 课题（LineTracker 为启发式，独立立项）。
- `host.attach_shell` 的 `preflightAttachment` 走同一 `captureBoundary(idle=true)` 检查，存在同类盲区；探测函数已可复用，v2 一行接入。
- `.trusted_edit` 的仲裁卡与 `switch_to_new_terminal` 选项留待后续。

## 测试

- `src/ai/host_conflict_arbiter.zig` 内联测试：邮箱生命周期（begin/snapshot/decide/wait/finish/supersede/stop）与 IME/粘贴文案非空。
- `src/ui/terminal_surface_tests.zig`：确认后可清理原草稿，过期的 IME、重新创建的同内容粘贴、异 Surface 回执都不得清理，普通队列保持不变。
- `src/ai_composer_interaction_view_tests.zig`：仲裁卡切换回普通审批时恢复可见和无障碍按钮文案。
- QA 场景（手动）：IME 组字中触发 AI 提交；粘贴确认模态挂着触发 AI 提交；普通打字竞态（应保留队列并返回只读提示）；仲裁挂起中停止会话（worker 应随 cancel 释放）。
