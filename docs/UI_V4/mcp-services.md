# MCP 服务列表

设计源：[常规列表](mcp-services.svg)、[窄版列表](mcp-services-compact.svg)。SVG 是可编辑的内容区参考，沿用 V4 晴霜配色；原生实现使用当前主题的 surface、well、selection、accent 和前景色，不固定浅色颜色。

服务名和地址占据左侧可伸缩区域。右侧依次为启停开关、“测试”、“查看”和更多菜单。编辑、网页登录、退出授权和移除收进更多菜单；移除使用危险操作样式。卡片标题右侧提供“添加”，不与折叠按钮嵌套。测试与授权只更新相应服务的状态，失败说明显示在该行下方。

| 元素 | 逻辑尺寸 |
| --- | --- |
| 服务行 | 最小高 66，水平内边距 10，垂直内边距 12，圆角 10 |
| 行间距 | 10 |
| 服务图标 | 28 圆形底，16 图标 |
| 名称 | 12.5 / 18，600 字重 |
| 地址与状态 | 11 / 16，次级前景色，名称下间距 3 |
| 右侧控件间距 | 10 |
| 启停开关 | 30 × 18 |
| 测试按钮 | 高 28，水平内边距 12，圆角 14；宽 48 |
| 查看／收起按钮 | 高 28，宽 48，圆角 14；未成功测试时禁用 |
| 更多按钮 | 28 × 28，16 图标 |
| 更多菜单 | 宽 180，向触发按钮末端对齐 |
| 错误说明 | 与名称左缘对齐，必要时换行并增加行高 |

名称和地址都只占一行，空间不足时省略；悬停名称可查看全文。地址去除 query 和 fragment，避免把参数或凭据带到列表。启停、测试、查看、更多操作保留固定宽度，名称区域最小宽度为 0。忙碌时禁用对应操作。保持既有全局保存、撤销语义。

工具详情默认收起；连接测试／网页登录完成只更新结果，不自动展开。成功测试后可点“查看”展开对应服务行内的只读预览，按钮切换为“收起”，再次点击恢复紧凑行高。查看只读取本次进程内已有的测试结果，不重新连接服务。详情绑定服务 ID 与配置 revision；移除服务或修改配置后不显示旧详情。不在 MCP 卡片外渲染共用预览区。卡片底部仅在出错时显示具体错误；连接测试、网页登录和配置更改成功后不显示说明或成功提示。

原生入口为 `src/config/ai_extensions_settings.zig`，局部样式为 `src/config/settings_mcp_styles.zig`。`e2e/mcp_reference_native.ts` 在 1280 × 900、860 × 480 窗口验证控件边界、菜单、启停、编辑及添加，并保存当前主题的原生截图；使用 `ZW_MCP_UI_ONLY=1 ZW_MCP_THEME=reference-light` 检查浅色。参考稿导出和实际截图放在仓库外的临时目录。
