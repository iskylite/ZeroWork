# 本地技能

助手输入框首行输入 `/` 打开命令菜单，选择 `/skill` 进入技能列表。直接输入 `/skill` 也可进入列表，紧接空格和关键字可过滤。列表只显示当前对话可用的已启用技能。上下方向键移动，回车或 Tab 选中，Esc 关闭并保留草稿。选择技能后，输入框填入技能引用，光标移到任务正文。发送时复用显式技能加载，后续回合按原版本续用。

选择器的 [SVG 基准](../../design/ai-skill-picker/index.svg) 复用助手浮层主题。菜单锚定输入框上方，边缘与输入框对齐，宽 320 逻辑点，距输入框 6 点。单行 32 点，行间距 4 点，内边距 6 点。超过六行时列表独立滚动，宽度和位置受窗口约束。

设计源：[常规列表](skills.svg)、[窄版列表](skills-compact.svg)。沿用 [MCP 服务列表](mcp-services.md) 的行高、字体、图标、开关、胶囊按钮和更多菜单尺寸，使用当前主题颜色。

技能列表上方使用单行工具栏，高 28：左侧显示“3 个技能 · 2 个启用”，右侧为“添加技能”按钮。不显示路径输入框、独立导入按钮或分开的文件／文件夹按钮。同一个系统选择器支持 SKILL.md、单个技能文件夹和包含多个技能的目录，选择后自动导入；取消不改变草稿。整个技能内容区保留拖入后自动导入。

技能行最小高 66，水平内边距 10、垂直内边距 12、圆角 10、行间距 10。左侧为 28 点图标、12.5 / 18 的名称和 11 / 16 的简介；名称和简介都只占一行并在不足时省略。右侧依次为 30 × 18 的启停开关、28 高的“查看”和 28 点更多按钮；重新导入和移除放进宽 180 的菜单。重新导入打开同一个文件／文件夹选择器，选中单个技能后自动替换。

正文默认收起；点“查看”读取并在对应技能行内展开，按钮切换为“收起”，再次点击关闭预览、恢复紧凑行高。正文绑定技能 ID 与 revision；移除技能或替换版本后，不把旧正文显示给其他项目。MCP 测试详情同样归属对应服务行，不使用列表外的共用预览区。卡片底部仅在出错时显示具体错误；导入、查看和配置更改成功后不显示说明或成功提示。

不增加技能文件数量或大小限制，保留原来的批量导入、流式复制、按需读取和全局保存／撤销事务。实现位于 `src/config/ai_extensions_settings.zig`，列表尺寸复用 `src/config/settings_mcp_styles.zig`。

定向验证使用 `e2e/ai_extensions_native.ts`：检查集合导入、错误、查看、菜单重新导入、移除后的详情归属，以及 1280 × 900／860 × 480 下的控件边界。`ZW_SKILLS_PICKER_HANDOFF=1` 写出 `picker-handoff.json`，由真实 UI 驱动完成取消、目录导入和 SKILL.md 重新导入，观察结果后向各阶段 `done` 路径写入 `done`；默认使用原生拖入事件，明确不覆盖系统选择器。`ZW_SKILLS_THEME=reference-light` 选择浅色，`ZW_SKILLS_UI_ONLY=1` 仅检查技能交互。完整运行同时检查 MCP 行内详情与保存／撤销、技能读取到 MCP 调用的原生链路。截图和报告保存在仓库外的临时目录。
