# 本地技能

设计源：[常规列表](skills.svg)、[窄版列表](skills-compact.svg)。沿用 [MCP 服务列表](mcp-services.md) 的行高、字体、图标、开关、胶囊按钮和更多菜单尺寸，使用当前主题颜色。

导入区域保留路径输入和文件／文件夹选择。路径同时支持 SKILL.md、单个技能文件夹和包含多个技能的目录；拖入行为不变。导入按钮高 28，输入框高 32，不重复显示展开卡片的说明。

技能行最小高 66，水平内边距 10、垂直内边距 12、圆角 10、行间距 10。左侧为 28 点图标、12.5 / 18 的名称和 11 / 16 的简介；名称和简介都只占一行并在不足时省略。右侧依次为 30 × 18 的启停开关、28 高的“查看”和 28 点更多按钮；重新导入和移除放进宽 180 的菜单。重新导入仍使用输入框中的单个技能路径。

正文默认收起；点“查看”读取并在对应技能行内展开，按钮切换为“收起”，再次点击关闭预览、恢复紧凑行高。正文绑定技能 ID 与 revision；移除技能或替换版本后，不把旧正文显示给其他项目。MCP 测试详情同样归属对应服务行，不使用列表外的共用预览区。卡片底部仅在出错时显示具体错误；导入、查看和配置更改成功后不显示说明或成功提示。

不增加技能文件数量或大小限制，保留原来的批量导入、流式复制、按需读取和全局保存／撤销事务。实现位于 `src/config/ai_extensions_settings.zig`，列表尺寸复用 `src/config/settings_mcp_styles.zig`。

定向验证使用 `e2e/ai_extensions_native.ts`：检查集合导入、错误、查看、菜单重新导入、移除后的详情归属，以及 1280 × 900／860 × 480 下的控件边界。`ZW_SKILLS_THEME=reference-light` 选择浅色，`ZW_SKILLS_UI_ONLY=1` 仅检查技能交互。完整运行同时检查 MCP 行内详情与保存／撤销、技能读取到 MCP 调用的原生链路。截图和报告保存在仓库外的临时目录。
