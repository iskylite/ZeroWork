## 3. 三种独立状态

| 状态 | 控制对象 | 生命周期 |
| --- | --- | --- |
| 允许AI读取 | 整库及其后代 | 持久化、默认关闭，只控制工具读取 |
| 文档只读 | 单篇标题、正文、图片及变更操作 | 持久化，手动解除；窗口／页签／浮窗／重启保持 |
| 渲染暂停 | 不可见的笔记呈现 | 自动按可见性控制，重开增量恢复；不显示额外状态标签 |

可编辑时用开锁图标，Tooltip「设为只读」；只读时闭锁＋「只读」，Tooltip「解除只读」。设只读先收敛输入／导入，原子保存草稿和状态；保存失败不伪报锁定。允许阅读、复制、搜索、看图；禁止标题／正文／图片编辑、文字撤销／重做、移动、删除及影响该文档路径的祖先变更，服务层同样校验。解除只读没有默认快捷键。

保存失败取消文档跳转／销毁／退出，保留原编辑实例。收起浮窗或切到其他连接只隐藏，不销毁由NotesStore持有的DocumentSession：立即停止视觉工作，必要保存继续，失败走已有通知入口，再次打开显示原草稿和错误。完整规则见方案§4.1／§5.2。

## 4. 快捷键、焦点与返回

| 动作 | 键位／入口 | 行为 |
| --- | --- | --- |
| 笔记浮窗 | ⌥⌘N；页签＋菜单「笔记浮窗」 | 任意连接会话／组中唤出或收起；标准笔记页已前台则聚焦该页 |
| 标准笔记页 | 原页签＋菜单「笔记」；浮窗「在页签中打开」 | 复用原插件页，交接同一文档／草稿／撤销／搜索栈，再隐藏浮窗 |
| 笔记目录 | ⌥⌘B；唯一目录按钮 | 只派发给前台／持焦笔记；保留⌘B左栏及⇧⌘B历史 |
| 搜索 | 笔记持焦时⌘F；搜索按钮 | 保存后进入，左上箭头返回原笔记 |
| 从命中返回 | 返回箭头／非编辑状态Escape | 先回查询／范围／选中行／滚动，再回原笔记位置 |
| 保存／粘贴／撤销 | ⌘S／⌘V／⌘Z、⇧⌘Z | 按焦点与只读状态处理，不透传到PTY／KVM |
| 收起浮窗 | 头部关闭／⌥⌘N／最外层Escape | 立即暂停渲染，焦点回到有效连接 |

⌥⌘N是设计键位。现有 `src/main.zig` 的N分支匹配过宽，须先接入notes_float配置，再把旧新建连接分支限定为精确⌘N；不能同时触发。两个新增动作都进入设置、冲突检测和序列化，不覆盖自定义键位；IME／模态／录制优先。不是全系统热键。

宽窗目录并列时可继续编辑。窄窗覆盖态先暂停输入、保留编辑位置，正文只接收返回动作；点击正文、选择文档或关闭目录后先收起覆盖，再恢复可见光标，点击不穿透成编辑／打开图片／链接。宽转窄且目录展开时执行同样的焦点移交。

Escape按IME → 子弹层 → 窄窗目录 → 结束块编辑 → 搜索返回层 → 收起浮窗逐层处理；编辑中的第一次Escape只结束当前块，未编辑时才执行搜索返回。宽窗目录仅在目录持焦时响应，连接持焦时Escape仍属于连接。浮窗外点击可操作连接但不自动关闭浮窗；失焦但仍可见的浮窗继续显示必要更新。

用户点击旧AI来源走本地访问上下文，关闭AI读取仍能打开本地笔记；打开本身不发送给模型。模型读取仍逐次授权。恢复同名目录必须显式确认新名称，不覆盖现有目录。

## 5. 渲染与组件契约

| SVG区域ID | 原生映射与约束 |
| --- | --- |
| `notes.floating` / `.surface` / `.header` | 内容槽内绝对布局box＋既有floating_surface激活顺序，不是新系统窗口 |
| `notes.floating.open-tab` / `.close` | 同一DocumentSession宿主交接／立即隐藏，不复制草稿 |
| `notes.navigation` / `.scroll` / `.toggle` | 普通并列侧栏或有界覆盖抽屉，独立ScrollArea／VirtualList |
| `notes.read-only.toggle` | Button触发显式只读事务，状态来自NotesStore |
| `notes.title` | 有120字符校验的EditableText；只读时可选中的显示文本 |
| `notes.editor.active` / `.preview` | 所有正文块统一Textarea，输入期间实例固定，预览按语法变化 |
| `notes.document.scroll` / `.image` / `.code` | 正文及代码块填满可用宽度；图片同一资源按原始尺寸显示，超宽才等比缩小 |
| `notes.search.back` / `.clear` / `.list` | 查询状态与两级返回栈，本地结果不变成AI缓存 |
| `notes.save.error` / `.retry` | 真实错误、草稿和重试，不把收起当成已保存 |
| `notes.restore.conflict` / `.name` / `.confirm` | Modal＋Input，校验父节点和名称后恢复 |

现有Markdown全文text变化会整控件重排；插件按块持有渲染结果，不声称框架已有整篇增量编辑器。稳定block_key、合并脏区、语法安全边界、视口及前后一屏预取、活动输入固定、缓存键和旧结果丢弃详见方案§11.4。

隐藏时取消预览／展示用图片解码／定时器，不布局、不绘制、不请求重绘，只保留最新版本和合并脏区。必要的图片导入验证、落盘及搜索快照发布属于数据工作，可继续。恢复先核对最新只读／权限／错误，无变化且缓存有效则复用，有变化只处理最终差异；缓存逐出或语法边界不确定允许正确性优先的重新解析，不承诺永远零布局。

当前renderer缺少可见性通知，需新增兼容的可选presentation_changed，focus_changed不能代替。15张静态图不能验证CPU／GPU、IME、快捷键或保存，不能据此声称隐藏零开销已实现。
