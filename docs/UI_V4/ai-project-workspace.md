## 实际 UI 基准

已查看当前运行的 ZeroWork AI 面板与附件菜单，并核对现有标准折叠卡片的原生截图及布局记录。几何和组件结构以以下实现为依据，配色使用 V4 晴霜主题。

- `src/ui/ai_assistant_header.zig`、`ai_assistant_styles.zig`：600 × 456 浮窗、14 点拖拽区、34 点标题栏、90 点输入区；六个标题栏按钮保持 22 × 22、间距 6。
- `src/ui/ai_composer_controls_view.zig`、`ai_composer_controls_styles.zig`：左侧附件／执行权限／运行方式，右侧上下文／模型与推理档位／发送，保留原有控件形式和排列。
- `src/ui/ai_tool_results_styles.zig`、`ai_step_view.zig`、`ai_step_disclosure.zig`：折叠卡片圆角 9、标题行高 32；左侧活动图标在展开、悬停或键盘聚焦时切换为展开箭头；摘要在中间、耗时在右侧；正文自然高度，上限 150。
- `src/config/theme_presets.zig`、`src/ui/theme_states.zig`：晴霜主题与派生的输入／操作背景。UI 使用内嵌 Inter Variable 和 PingFang SC，代码使用内嵌 JetBrains Mono。

## 本次新增

1. 现有“＋”附件菜单末尾增加分隔线和“设置本地工作区…”；点击调用系统目录选择器，取消保持原目录。四个现有菜单项不调整。
2. 标题栏会话归属后、现有弹性空白中增加与原控件同高的目录项：文件夹图标、basename、下拉箭头。图中为 `ZeroWork`；悬停显示完整路径，点击沿现有 Popover 样式提供当前路径、更换目录和移除工作区。移除只清除偏好，不删除文件。未设置且无活动任务待通知时不显示此项；不可用及等待模型刷新时在原目录项内提供提示。长目录名省略，缩小时优先压缩新增目录项，不挤掉原操作按钮。
3. 文件修改沿用标准折叠步骤卡片。收起显示“修改文件 · basename · +N −N”和耗时；展开正文显示操作时的路径、行号与逐次增删内容，完整绝对目标可核对。图中分别展示一张展开和一张收起的修改卡片，没有另建独立文件面板。

## 组件内状态

| 场景 | 显示与退出条件 |
| --- | --- |
| 设置／更换后等待活动任务更新 | 显示已提交的新 basename，在原目录项提示待更新；最新通知 ack 后清除提示，不产生用户消息气泡 |
| 活动任务中移除 | 原位置暂留“已移除”，提示“本地工作区已移除，等待当前任务更新”；权威状态立即为 none。最新通知 ack 或活动任务终结后收起；未交付事实保留到下一次合法请求 |
| 移除后立即设置 B、旧通知晚回 | 显示 B 和其待更新状态；旧 ack 不清除较新状态，发送未知不当作已送达 |
| 不可用 | 原目录项提示原因并保留重选入口；不切换到 Home 或终端 cwd |
| 提交前版本／审批冲突 | 使用标准失败状态，明确未写入；保留实际目标与原因 |
| 已提交后检测到外部并发 | 使用标准冲突／失败状态，显示“文件已写入，检测到并发修改”；详情说明原内容已保留及恢复定位，不显示“未修改”或成功，不提供自动回滚 |
| unknown、差异材料过期 | 保留未知或过期事实；当前只读核验与原提交结果分开，不能用空差异表示无改动 |

目录状态和修改卡片分别消费权威工作区记录与原 operation 记录。标题栏切目录不改旧卡片目标；多个步骤间的用户修改不合入 AI 差异。两份 SVG 保持正常状态设计，以上异常／过渡状态在同一组件实现，不增加侧栏、整行说明或独立文件面板。

画布 664 × 520，仅为真实尺寸浮窗四周保留预览阴影空间；浮窗位置 x32/y24、尺寸 600 × 456。两份 SVG 的基础面板相同，设置态仅叠加附件菜单。

本次交付为可编辑 SVG 与行为契约；2026-11-11 修订补齐组件内过渡／冲突状态，正常态 SVG 布局保持。对话、文件差异及耗时为设计数据，未实现原生功能或目录选择交互。
