# V0.6 网页连接 · SVG 设计

当前产品与实施依据为 [V0.6 网页连接插件](../DESIGN/V0.6_WEB_CONNECTION.md)。[V0.6.1 AI 浏览器交互](../DESIGN/V0.6.1_WEB_AI_CONTROL.md) 为可选、非必要扩展，不计入本版完成条件。

浏览器（web，原「网页」）是与 SSH、SFTP、BMC 同级的内置连接插件，本质上是打开一个浏览器环境方便访问内网网址。资产出现在「主机与连接」，打开时创建工作区页签。**页签的内容就是网页**：ZeroWork 提供原生工具栏、连接进度和错误状态，macOS 的 WKWebView 只渲染站点内容。浏览器不依附某个 SSH 终端，无需先打开终端或系统浏览器。

「＋ → 新建浏览器」直接打开已选中「浏览器」的连接向导。侧栏的「新建连接」也可进入同一向导。

## 网址与路径是两项独立设置

| | 预设网址 | 手动输入 |
| --- | --- | --- |
| 编辑连接 | 「起始网址」必填，资产保存完整 HTTP(S) URL | 不显示起始网址；可保存名称和路径，作为可重复使用的内网网页入口 |
| 打开页签 | 直连立即加载。经 SSH 跳板时自动建立本页签的转发，代理就绪后访问起始网址 | 打开时聚焦地址栏。提交有效网址或打开书签后才启动所需连接 |
| 网页内导航 | 可编辑地址栏，回车沿当前路径访问新网址；「回到起始网址」再次访问保存的入口 | 同样可编辑地址栏并复用当前路径 |
| 关闭并重新打开 | 从保存的起始网址重新开始 | 回到空白，不恢复上次网址或历史；显式保存的书签仍可用 |

- 添加跳板只改连接草稿。「仅保存」校验格式和引用后保存；「保存并连接」保存后打开页签，「临时连接」直接打开页签。
- 两处共用地址解析。接受 HTTP 和 HTTPS，无协议时补 HTTPS；不转搜索、不从 HTTPS 自动降级、不接受带用户名密码的 URL。长地址未编辑时省略路径，保留可辨认的来源；复制获得完整当前地址。地址栏编辑期间保留草稿，旧导航回调不能覆盖草稿；Esc 撤销未提交输入。
- 「直接连接」使用本机网络，不启动 SSH。「经 SSH 跳板」按顺序引用 1–8 个已保存的 SSH 资产，最后一台是网页流量出口，网页主机不计为一跳。选择器、排序、删除和认证交互沿用现有控件。使用显式路径，不递归展开某台资产自己保存的跳板。缺失、重复或协议不匹配的资产在提交前指出具体行。
- 配置模型为 URL 模式、可选的起始 URL、路线模式与有序 SSH 资产 ID。资产 ID、名称、分组和版本由公共 ConnectionEnvelope 管理。运行时冻结配置与路径快照，后续编辑在下次打开时生效。网页连接不复制 SSH 密码、密钥或 OTP；网站登录在网页内完成。

## 工作区与交互

- 右上角的转发入口在网页页签打开当前网页会话的只读状态，窄窗时从右上角「…」展开工具组。面板显示跳板顺序及实际转发状态，监听就绪时显示系统分配的 `127.0.0.1:端口`，断开或清理时移除旧端口。直连显示「直接连接」。页签之间只复用跳板资产配置，每个页签各自建立 SSH 链和监听。
- 工具栏从左到右为后退、前进、重新加载或停止加载、地址、书签、更多。无法操作时禁用。地址栏右端的五角星用于收藏当前页。更多包含「复制网址」，预设连接另有「回到起始网址」；窄窗时收纳点击即可打开的书签列表，不设置「管理书签」。两种模式都可点击编辑地址，⌘L 聚焦并选中完整网址。回车在当前页签导航，资产的起始网址在连接设置中编辑。宿主优先处理应用快捷键，网页获得自己的输入、滚动、文本选择和 IME。
- **路径与页面分别记状态。** 路径可待启动、逐跳认证、监听就绪、断开或关闭；页面可空白、加载、已显示或加载失败。监听成功不代表网页可达。HTTP 4xx/5xx 保留站点自己的页面；域名解析、证书、转发中断和 WebKit 内容进程退出分别给出对应操作。
- 手动模式第一次提交有效 URL 或打开书签才启动 SSH，预设模式打开即启动。建链时显示「正在连接 SSH」和跳板顺序，代理绑定到当前页签的 WebKit 数据仓后显示「正在加载网页」。逐跳认证沿用主机信任、密钥、密码和 OTP 流程，可取消。失败保留页签和目标地址。断线时提供「重新连接」与「查看路径」，操作前显示「重新连接将清除网页登录、未提交内容和浏览历史。」所有重连入口共用提示，未展示影响时先定位断线页并保留目标，由用户点击重连。重连使用冻结路线和全新 WebView／非持久数据仓，不迁移 Cookie、网站存储、表单、滚动位置和历史，保留页签身份、配置与书签。成功后首次页面显示一次「连接已恢复，请重新登录网站。」首次建链失败重试不误报登录丢失。
- 重连先访问用户明确选择的书签或新地址；没有新目标时仅恢复当前文档已确认的普通 GET。POST／未知方法或结果不转成 GET、不重放，等待用户回到预设入口、输入新地址或选择书签。普通刷新、切页签、浮层和临时 unmount 不重置数据仓；WebContent 失败仅在确需重建数据仓时采用相同重置提示。具体行为以 [§3.1](../DESIGN/V0.6_WEB_CONNECTION.md#31-重连与网页会话重置) 为准。
- 切换页签或暂时显示宿主浮层只隐藏网页视图，保留浏览位置、历史与登录。关闭页签停止导航、撤下视图，停监听、收尾转发流、关闭 SSH 链并等待清理回执。打开、重连、关闭均绑定会话 generation 和操作 ID；晚到事件不能修改其他页签，也不能替已关闭的页签重新打开网页。
- 首版每个页签、每次网页会话使用独立的非持久网站数据存储；关闭或重建后重新登录是预期行为。用户触发的普通新窗口链接可沿当前路径在本页打开；依赖独立弹窗与 opener 的登录流程不承诺兼容。下载若未接入宿主选址和进度，明确提示不支持。不给网页注入可调用 ZeroWork、SSH 或 AI 的脚本接口，首版也不注册 AI 页面操作。

## 书签

**左键单击直接打开，空心星收藏，右键编辑或移除。** 日常使用不经过管理页或列表表单，连接编辑器不提供正常书签管理入口。

- **数量上限**：每个保存连接及每个临时连接最多 16 个书签。第 16 项正常加入，第 17 个不同网址提示「最多保存 16 个书签，请先移除一个」。同网址定位已有项，满额仍可编辑或移除。并发新增按最新资产 revision 原子去重并检查容量，保存失败保留原列表与星标状态。
- **位置与滚动**：书签紧接 URL 地址栏，位于「更多」左侧。按内容取宽，最多 328 点（含滚动按钮），高度 32；未超宽时不显示左右按钮。超宽后只在该区域横向滚动：可用触控板横滑，或点两侧箭头移动一项；到头禁用对应箭头。地址栏和其他按钮不会随书签移动。单个书签按标题取宽，范围 74–104 点（含左右各 10 点内边距）。标题单行末尾省略，悬停或聚焦可读全名；键盘焦点进入被裁切的书签时自动滚到可见。没有书签时收起整个区域。
- **点击**：书签条／窄窗列表的左键单击或 Enter 直接在当前页签访问该 URL，不弹出编辑或管理界面。导航进入前进／后退历史，不修改预设起始网址。手动页未启动 SSH 时自动沿原路径建链；断线按既定重连规则处理，就绪后打开该书签，不额外要求进入书签管理。认证期间只保留最后一次明确的导航意图，丢弃关闭后的迟到结果。
- **收藏**：点击空心星直接保存当前已提交 HTTP(S) 页面，标题取页面标题或域名；成功后变实心，不自动弹出表单。再点实心星可编辑。空白／错误页禁用添加，已有书签仍可右键操作。同资产共享清单，临时连接仅在本会话保留。导航与收藏分开，输入网址不会自动新增书签。
- **右键**：条目菜单仅提供「编辑书签…」「移除」，键盘上下文菜单等价。操作对象为该书签 ID，A 重定向到 B 或无法访问时仍可右键 A；无需先加载成功。右键只开菜单，不导航。编辑使用条目附近的小浮层，仅有名称、网址、保存和取消；长值可横向编辑／复制，重复 URL 提示冲突并保留草稿。
- **写入**：保存／移除按最新 revision 原子更新，临时连接只改内存。外部改动同一项时保留草稿并提示，不复活已删除项；取消、Esc 或关闭编辑浮层丢弃未保存改动。普通连接配置保存也不能用旧 payload 覆盖新书签。所有维护操作不发网络请求。
- **异常修复**：仅检测到已知版本的超限／损坏数据时进入「修复书签」，不提供常驻入口。完整列出原条目供修正／移除；数量 ≤16、字段合法且无重复才启用「应用修复」，返回连接编辑器统一保存。取消或写入失败保留原磁盘数据。正常书签操作不进入此页。详情见 [§4.4](../DESIGN/V0.6_WEB_CONNECTION.md#44-右键编辑与异常修复)。
- **窄窗**：先缩书签区，地址栏保留至少 132 点。若无法容纳一项可点击书签和两个滚动按钮，书签移入「更多 → 书签」，仍可直接点击跳转。

## 原生接入与传输

| 边界 | 做法 |
| --- | --- |
| 插件注册 | 参考 [BMC 注册方式](../../src/plugins/bmc_ikvm/plugin.zig)，贡献连接编辑器、版本化 payload、session factory、content renderer 与连接状态和详情。以 ContentMount.owner 标识归属。首版与 BMC 一样不开启跨窗口拖拽，直至原生视图迁移验证通过。 |
| Zenit / AppKit | Zenit 绘制外壳、工具栏、输入和错误视图。宿主提供受限的原生视图挂载接口，按内容槽实际窗口、矩形、裁剪、可见性与焦点，在 AppKit 主线程挂载 WKWebView。使用真实 NSView，不把网页转成 Metal 纹理。先验证网页与宿主弹窗、AI 浮层的层级和命中；若当前渲染路径无法在正文上方显示浮层，首版可在覆盖期间隐藏网页视图并保留实例。SVG 用暗化正文表达理想层级。 |
| 路线所有权 | 网页经多跳访问非回环目标时，WKWebView → 会话自己的本地 SOCKS5 → SSH 出口 → 网站。复用 [freezeRoute](../../src/host/connection_config_resolver.zig)、SSH 认证和 direct-tcpip 能力，参考 BMC 以网页会话 owner 申请独立 transport。现有 [socks_route_host](../../src/host/socks_route_host.zig) 面向已有 SSH owner，且同一 owner 已有活动转发时会拒绝第二个；不能直接借用用户的终端监听。需要把网页自己的 transport 接到现有 SOCKS 监听和转发引擎，并验证并发和资源释放。 |
| 回环目标 | localhost、127.0.0.1、::1 等保留本机语义，顶层导航、重定向与页面子资源访问运行 ZeroWork 的本机属于预期行为，不作为代理故障或交付阻塞。出口与断链回退验证使用非回环目标，见 [§5](../DESIGN/V0.6_WEB_CONNECTION.md#5-网络与平台)。 |
| 代理绑定 | 只监听 127.0.0.1，使用临时端口和每代独立的随机认证凭证；本代数据仓绑定本代代理，对需要代理的非回环目标禁止直连回退。SOCKS5 拒绝无认证／旧凭证，认证后开流前复验 owner/generation；旧数据仓不绑定新代理。凭证不进入配置、UI 或日志。WebKit 认证及强制复用旧端口隔离必须在阶段 A 验证，不通过则不交付 SSH 网页能力；不退回无认证。 |
| 回收终态 | 输入及代次撤销、pending 回调／桥接任务结清、surface／原生强引用释放、监听及 worker 退出、握手／排队／活动流归零、transport 返回 released 后，本代自有资源即可发布 released。WebKit 内部引用与共享网络进程的退出不可作为正常回收前提；新代认证阻断端口复用后的旧请求。只有真实未释放资源保留有界回收记录，不永久保留旧监听。见 [§6.4](../DESIGN/V0.6_WEB_CONNECTION.md#64-关闭前检查与回收)。 |
| 原始网址 | 保留原域名、端口、HTTP Host、TLS SNI 与正常证书校验，让重定向、Cookie 和跨域资源按原始站点规则工作。证书不受信任时显示错误。只在出口可解析的域名、跨域资源、WebSocket 和目标站点登录流程均需实测；SOCKS TCP 路线不等同于系统 VPN，不承诺 UDP/WebRTC。 |
| 平台与包体 | [WebView 专用代理 API](https://developer.apple.com/documentation/webkit/wkwebsitedatastore/proxyconfigurations-6g21z) 从 macOS 14 起可用；本轮网页连接在当前目标系统验收，记录实际 OS/SDK。使用系统 WebKit 与 Network.framework，无浏览器引擎随 DMG 分发。插件和桥接代码的增量以 ReleaseFast 同条件打包结果为准。 |

[Apple：SOCKS5 与直连回退](https://developer.apple.com/documentation/network/proxyconfiguration) · [非持久网站数据](https://developer.apple.com/documentation/webkit/wkwebsitedatastore/nonpersistent%28%29) · [网页弹窗行为](https://developer.apple.com/documentation/webkit/wkuidelegate)

## 布局约定

- SVG 和浏览器导出均为 1440 × 900，viewBox 为 0 0 1440 900，1× 导出。沿用晴霜配色、工作区胶囊、侧栏和页签；界面用系统字体与 PingFang SC 回退。产品文案和网页示例保留可编辑文字。
- 展开侧栏宽 238，左边距 12，工作区从 x=274 起。web.toolbar 位于 (274, 70)，1154 × 44，导航按钮命中区 28 × 28，地址栏高 32。若 AI 三点条显示，沿用 y=59–65 的悬浮位置，不挤占工具栏。web.document / web.state 从 (274, 126) 开始，到右、下边距 12 为止。工具栏固定高度，正文填满并由 WebKit 滚动。
- 工具栏和网页随工作区缩放布局，不整体等比缩小。先按书签的窄窗规则让出空间；若内容区仍不足以容纳 132 点地址栏和全部操作，前进、后退依次收进「更多」，保留地址和加载控制。长路径节点名在选择器内省略，展开可看全名。网页使用现有连接向导的协议选择和 760 点宽外壳。连接路径采用同一个直连／跳板卡片、拓扑和滚动布局，以 [SSH 向导路径](../DESIGN/connection-wizard/ssh-route.svg) 和 [纵向路径](../DESIGN/connection-wizard/ssh-route-vertical.svg) 为准。网页编辑稿用于参考专属表单字段。表单正文滚动，标题和操作栏固定。
- 书签右键菜单在本画布为 (1162, 112)、160 × 80；编辑浮层为 (1036, 116)、380 × 230，锚定所选书签或星标，在窗口边界内避让，不加全屏遮罩。窄窗限制为内容区可用宽度，字段填充，保存／取消保留。浮层关闭后焦点回到原书签／星标，移除后落到相邻项。

## 实施与验收顺序

1. **原生容器**：把 WKWebView 挂进当前 Zenit 内容槽，实测窗口尺寸、缩放、前后台切换、浮层覆盖、鼠标、选择和中文 IME。
2. **代理**：用两个 SSH 跳板和一个仅出口可解析的 HTTPS 测试站，验证并发资源、原域名与证书、重定向、Cookie、WebSocket、代理认证、断链无直连。强制复用旧端口，验证旧 WebView／旧凭证不能打开新代流，两数据仓不串用凭证。固定夹具连续 20 轮打开／关闭及 20 轮断线／重连，检查每轮旧代 FD、监听、worker、流、pending 回调和回收记录回到基线；真实清理失败只占用有界预算，完成后恢复。并开 SSH 终端与多个网页页签，关闭其中一个不影响其他会话。
3. **插件**：覆盖预设/手动 × 直连/跳板四种组合，检查离线保存、临时连接、取消逐跳认证、页面错误与路径错误分离。已登录且有表单草稿／历史时验证所有重连入口先告知重置、新仓无旧登录及页面状态、书签配置保留，普通刷新／切页签不误重置；不重放 POST 或未知请求。检查 0/1/15/16/17 项边界、并发新增与写入失败、重定向／失效书签的独立编辑移除、修复草稿与取消／冲突、长标题省略、首尾滚动、键盘、窄窗和书签建链。保存原生截图与 SVG 对照，再用相同签名和流程实测 DMG、更新 ZIP 与运行内存。

测试入口与原生验证步骤见 [端到端测试说明](../../e2e/README.md#网页连接的原生验收)。
