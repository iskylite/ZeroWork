# 通知关闭时间

原生实现以 [倒计时 SVG](../../design/command-error-countdown/countdown.svg) 的操作区为参考。卡片沿用现有 340 点宽、12 点圆角和 16 点左右内边距；计时区宽 80 点，时钟图标 12 点，图标与文字间距 4 点，文字 10 点、18 点行高，颜色使用当前主题 `fg_2`。操作按钮保留已有尺寸。字体跟随原生系统字体；SVG 使用 PingFang SC / Helvetica Neue 回退。SVG 画布为 404×178 逻辑点。

| 通知表面 | 处理 |
| --- | --- |
| 命令执行失败卡片 | “询问 AI”左侧显示真实的 8 秒关闭倒计时，每秒更新 |
| 全局通知卡片：连接、传输、AI、插件、应用级风险 | 操作区显示真实关闭倒计时；沿用有操作 8 秒、无操作 4 秒的原策略；风险级别不再隐藏计时 |
| 悬停、键盘焦点、展开详情等停止自动关闭的状态 | 隐藏整个计时区，不显示“已暂停”；恢复计时后显示实际剩余时间，保留原有重新计时策略 |
| 就地成功回执、复制按钮反馈 | 维持现有短时反馈，不增加计时文案 |
| 通知历史与待处理事项、会话断线/重连状态、AI 阻塞说明、认证/审批/冲突确认 | 根据事项状态保留，不增加自动关闭倒计时；已有“自动重连”时间继续表达重连行为 |
| macOS 系统通知 | 系统管理显示时长，应用不伪造关闭时间 |

计时区与操作按钮为同一原生行，长来源文字可收缩，操作文本使用现有省略规则；展开后的完整详情与附加操作保留原生滚动。倒计时不使用 live-region 逐秒播报，不改变通知正文与原始动作归属。关闭浮层保留全局通知记录和未解决状态。

实现：`notification_countdown.zig` 复用显示逻辑，两类通知各自保留现有计时与交互策略；只在下一秒边界唤醒命令卡片，不使用持续重绘。原生验证通过 `e2e/notification_countdown_native.ts`，使用隔离配置和生产控件，覆盖三主题、悬停、恢复、自动关闭、展开详情、最小窗口长文本与历史保留。
