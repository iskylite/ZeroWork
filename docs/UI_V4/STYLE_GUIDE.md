# SVG 主界面风格指南

## 视觉方向

白色胶囊组件悬浮在连续工作画布上。用清楚的圆弧轮廓、轻柔的下投影及留白表达层次；核心终端区域直接落在画布，不增加包围终端的卡片。减少次要标签和描述，让布局传达关系。

功能区由独立组件组成。组件间保留画布，投影应柔和分离；不能把三组工具画成一条连在一起的底板。恢复白底后不额外叠加灰紫色或降低原透明度。

## 当前尺寸与形状

| 项目 | 规范（逻辑点） |

| 工具按钮／图标 | 28×28圆形／16×16；按钮圆角14 |

| App 外留白／侧栏到工作区 | 12／24 |
| 终端视口／首行文字上沿 | y60／y76，文字四边内距16 |
| 底部新建连接 | 遵循通用规范 M-NEWHOST：高34，圆角8，1.5px虚线井；默认透明，文字用fg-2、虚线用well-bd；hover使用统一selected状态（sel-bg语义）、accent虚线和可读accent文字，无位移／阴影；键盘焦点用底色，无实线外框 |

顶部组件真实下沿48，首行文字上沿76，两者间隔28；AI 条中心取二者中点。它不占布局空间，不因显示或状态变化推移终端。

宽窗与窄窗维持同一套尺寸；窄窗收为一个36×36三点组件，点击后向左展开全部工具、隐藏三点，移出整个功能区收回；所属弹层保持可操作。

## 晴霜主题与透明度

- 白色悬浮表面：SVG `#FFFFFF`；原生使用现有主题的 `overlay` 颜色与原 alpha，不另乘透明度系数。
- 选中 Tab：SVG `#EAEDFD`；原生使用 `selection`。
- 画布 `#FFFFFF`、侧栏 `#F6F6F7`、正文 `#18181B`、次级文字 `#5B5B65`、辅助文字 `#676771`、强调色 `#4F5ED9`。
- 原生其他主题继续使用各自 token；不得把晴霜硬编码到所有主题。
- 主题真实源为 `src/config/theme_presets.zig`。辅助文字原生微调以该源为准；颜色改变须核对实际合成背景与可读性。

参考图的主要实色为白色 `#FFFFFF`、侧栏浅灰 `#F6F6F7`、选中蓝底 `#EAEDFD`、强调蓝 `#4F5ED9`。主题独立注册为 `reference-light`（晴霜），保留 `mist`（雾紫 · Mist）。当前三个 SVG 使用晴霜；辅助文字按既有4.5:1要求校正，避免照搬截图中偏浅的灰字。

顶部图标按钮在常态、悬停、按下、键盘聚焦和主题切换后均使用同一圆形轮廓，28×28对应圆角14；关闭按钮20×20对应圆角10。状态仅改变填色／描边，不退回圆角矩形，不改变尺寸和间距。常态透明，hover 使用当前主题的圆形悬停底色，按住时使用短暂的按下底色。点击完成后恢复透明；鼠标留在原处时不立即重新点亮，移出再进入才重新触发 hover。菜单暂时接管命中目标不算鼠标实际移出。禁用按钮不显示操作反馈；键盘聚焦使用 1px 主题强调色圆形描边，与鼠标背景独立，不用持续填色代替焦点；连接状态点、传输进度、广播状态和 Tab 选中底色独立保留。

## 高斯模糊与悬浮投影

当前 SVG 用 `feDropShadow`：`dx=0`、`dy=3`、`stdDeviation=4`、`flood-color=#18181B`、`flood-opacity=0.07`。

`stdDeviation` 是高斯分布的标准差 σ，单位随 SVG 逻辑坐标，不等同于 CSS blur radius，也不等同于原生 SDF 的 blur。当前 σ=4，约3σ范围为12；dy3使下方投影延伸更明显。导出2倍图时由渲染器统一缩放，源参数不能再乘2。

滤镜区域必须容纳完整阴影，不能被对象默认边界截断；尤其要检查36宽的窄窗三点组件。当前共用 filter 区域取 x/y=-50%/-60%、width/height=200%/240%，保证最小组件也有足够扩散余量。滤镜边界不参与排版和命中区计算。

SVG 滤镜默认在线性 RGB 空间处理；未经对比不要随意改变 `color-interpolation-filters`。最终颜色还受到背景、透明度及显示合成影响。

原生 zenit 当前采用 SDF 距离场平滑衰减，不是真正的高斯卷积。根据实际画面对齐，顶部原生投影使用 `blur=8`、`offset_y=3`、alpha `20/255`。这组参数用于对应当前 SVG 的视觉效果，不能把 SVG 的 σ 或 CSS 半径直接抄成原生 blur。

校准应同时观察下沿的阴影深浅、衰减范围、圆角周围轮廓及相邻组间留白。像素采样只能辅助检查局部投影；小范围数值接近不证明整页已对齐。设计稿与原生都必须亲自查看。

## 字体、图标与状态

界面采用系统字体／PingFang SC，终端设计示例采用 JetBrains Mono。原生保留用户终端字体偏好。普通工具统一图标尺寸与中心，不靠不同留白修补单个图标。

颜色和状态点表达真实连接、传输和 AI 状态。AI 浮条只显示三个点，保留原来的玻璃构型、悬停、点击固定、离开处理与状态节奏，不增加文字或新状态标签。

## 存储与导出

本设计目录只保存 SVG 和 Markdown。PNG、参考照片、原生截图、差异图、像素数据及验证记录均存放在目录外。SVG 预览可直接打开原稿；需要栅格导出时，目标目录必须是 `/tmp` 或 `artifacts/ui-v4/`。
