# 端口转发气泡

- 原型：index.html，运行、启动中、失败、停止状态；日志按钮展开关键步骤耗时（原型为示例值）。
- 浏览器测量：1210×785 CSS px，DPR 2，100% 缩放。气泡宽 380，padding 16；标题高 26、下间距 12；规则卡 padding 12、gap 6；标题 15/20，右侧浅色 #主机名 12/18（无会话编号）；状态 15/20、监听地址 Menlo 18/26、元数据 12/20、累计流量 15/20、连接信息 12/20 主文字色；底部操作高 45、上间距 14。
- 原生使用项目内 vendor/zenit 实际 API、Popover / ScrollArea / Button；跟随现有主题色与材质，不覆盖应用配色。
- 主层级：状态 → 地址 → 访问范围、所属会话、出口 → 流量与连接数。固定操作：测试、配置、启动/停止/重试；复制在地址旁，日志图标位于连接信息行右侧，与复制按钮同为 28×28、16px 图标，悬停提示“查看日志”，日志图标打开独立日志气泡，关闭后返回概览。
- 底栏保留状态文字，窄窗口也不隐藏。监听就绪仅证明监听启动成功；目标连接结果在日志与测试结果中单独展示。
- 日志由 IO owner 记录，值快照交给 UI；单调时钟计时，跨 EAGAIN 重试累计。最近 24 条，明确省略数量。不记录认证材料或流量内容。
- 原生小窗口正文滚动，底部操作固定；独立日志气泡保留自己的滚动位置。CSS 与 Metal 字体栅格及主题材质存在平台差异。

- 操作颜色：启动/重试使用主题色；启动中禁用并使用中性色；停止操作使用红色文字。HTML 与原生状态一致。
- 深色状态色与原型一致：运行 #4BD18A，启动/暂停 #E8BD71，失败 #FF9D9D。底栏共用相同颜色。主操作的默认、悬停、按下样式同步更新；状态切换立即呈现目标背景。

- 概览保持 380px 宽，内容区固定 320px；独立日志气泡为 560×420px（约 4:3），只显示标题、主机名、关闭按钮和可滚动日志；小窗口按可用高度缩小，正文内部滚动，各自内容更新不改变气泡尺寸。日志格式为本地时间 HH:mm:ss.SSS - 日志 - 耗时（无耗时则省略末段），错误归入日志正文。测试成功结果 5 秒后清除，失败结果保留。

- 日志视觉：沿用现有浮层材质；16px 外内边距，28px 标题行（14px/600、16px 日志图标、右侧 28px 关闭按钮），主机名与最近条数置于次行（12/18），下间距 14px。日志阅读区使用 popupInset 背景、8px 圆角、细边框、12px 内边距；正文 Menlo 等宽字体 12px/21px、常规字重 400。HTML 实测外框 560×420，标题宽 528，阅读区 528×326；原生按同一约束实现。无尺寸过渡动画。
