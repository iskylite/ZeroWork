# 状态气泡与传输触发区

本次范围：统一浮层可读性、会话连接/连接链路层级、底栏转发与传输状态，以及会话传输预览交互。

- 可编辑原型：index.html。原型视口以桌面内容区为准，气泡380px、padding16、标题15px。原生沿用现有节点控件、字体和主题。
- 会话连接：标题/状态 → 主机与身份摘要 → 协议、延迟、加密、会话、路径 → 操作。380×348；长内容独立滚动、底部操作固定。
- 连接链路：380px，按跳数增加高度；保留节点详情、复制、日志、编辑、全链路测试能力。
- 弹出层背景透明度单独限制为4%–16%，对应alpha8为245–214；全局透明度继续作用于背景与其他图层，前景文字和图标保持完整不透明度。
- 端口转发：名称固定，状态颜色只用于图标。真实端口/失败来源仍为当前会话快照，详情在气泡中查看。
- 会话传输：空闲触发区按图标与文字内容自适应，左右各7px，不预留任务文字宽度，无默认背景、无进度轨道、无展开箭头；有任务时保持原264px任务摘要。空闲图标/文字与相邻底栏项同级。
- 悬停显示预览，允许150ms跨越触发区与气泡之间的间隙；离开二者后关闭。点击固定打开，移开保持，×关闭，关闭后不因同一次停留立刻重开；切换会话清除旧所属列表。
- 原型浏览器测量暂受浏览器连接故障限制；原生尺寸/状态通过现有Harness读取并截图验证，不能将源CSS数值冒称浏览器实测。
