# AI 远程文件选择窗口

任务：从当前助手所属的远程会话选择文件，把内容附加到对话草稿。沿用 V3 深色浮层，突出文件选择和右下角“附加文件”。本目录是此次局部改版的可编辑基准。

## 行为映射

- 输入框中单独键入 `/`，通过原生 Textarea 捕获事件，在下一安全帧打开文件选择窗口，保留已有提问；路径、URL、整段粘贴和 IME 组字不触发。
- 打开窗口优先使用终端已上报目录；没有目录时用 SFTP 的 `.` 查询默认目录，并把服务端返回的绝对路径写回输入框。文件内容读取仍要求绝对路径。
- 点击目录名进入目录；点击文件名或复选框切换选择。目录不显示复选框。
- 路径输入后按 Enter 或点击“打开”；“主目录”重新解析 SFTP 默认目录，“上级”根据当前绝对路径导航。
- 无选中项时禁用附加；仅选中一个文件时允许预览。多文件附加结束后关闭选择窗口。
- 列表区域显示加载、无匹配、空目录或读取错误，失败时保留输入路径以便修改或重试。
- 每个文件默认读取上限 4 KiB，保留既有截断与快照语义。
- 使用既有 Modal 开合及原生控件 hover/focus 状态，没有新增动效系统。
