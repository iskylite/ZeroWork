# @dots

仅显示收款二维码和“支付宝扫码 · 捐献支持开发”。

- HTML 基准：`index.html`，`.result`；本次浏览器视口 1280×720 CSS px，DPR 2，100% 缩放。
- 二维码：33×33 模块；四周各 4 模块白边；每模块 5px，外框 205×205px；纯黑与纯白，不随主题变色。
- 原生输出保留整行几何：验收配置 Menlo 14px / 行高 21px，二维码占 10 行，共 210px，提示紧随其后；字体复用终端配置。
- 窄窗口：按可用宽度将模块缩至整数 1–5px，保持白边和正方形。
- 原生输出复用现有内置指令记录；二维码不经过 PTY，不需要图像协议。
- 资源：`src/ui/assets/donation-qr.txt`，由用户提供的支付宝收款码解码后以纠错 M 重新生成。
