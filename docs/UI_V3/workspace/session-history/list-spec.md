# 历史会话列表操作

基准：`app.js` 的 `.history-list-panel`，复用工作区全局主题与字体。

- 面板宽 480，padding 16，圆角 12；随窗口可用宽度收缩。
- 每条记录高 66，padding `8px 9px`，主图标 16，图文间隔 10。
- 标题 13 / 500 / 18，次要信息 12 / 400 / 17。状态改用现有静态 Tag：高 20、水平内距 6、圆角 4、无描边，文字 11 / 400 / 16 居中。未录制／正常结束／旧版记录用中性色，内容缺口／连接中断／版本不支持用警示色，异常结束／录制不可用用错误色；均使用全局 Tag 与文字 tokens。
- 每条记录两行：第一行主机与时间；第二行连接信息、时长、状态和右侧查看／导出／删除。操作按钮为 28×28 的图标按钮，图标 14，悬停或聚焦显示提示。三者常态均无背景，悬停、按下和焦点沿用主 UI 的 ghost 状态。
- 点击记录正文不打开会话；搜索框 Enter 只把焦点移到查看按钮，按钮激活才打开只读历史。
- 正常录制可查看、导出；缺少起始状态且仍有文件时只允许导出片段；未录制或文件不可用时对应按钮置灰并提示。
- 清空列表作用于全部筛选结果（包含其他分页），确认时冻结记录身份与版本；随后新增的记录不在本次范围。
- 单条删除与清空均使用贴近对应操作按钮的小气泡：宽 288、padding 12、圆角 10，不占据列表布局；标题为“删除这 N 条记录？”，次行提示“录制文件也会删除，无法撤销。”。可取消、按 Esc 或点气泡外返回；后台删除，正在查看、导出或录制的记录保持受保护。
- 移除底部“已关闭会话 · 按结束时间排序”说明；排序行为保持不变。
- 空状态使用 200 高的列表内容区，图标 28、标题 13 / 500 / 18、说明 12 / 400 / 17，作为一组水平与垂直居中。窗口可用高度不足时内容区收缩。
- 删除全部成功后只更新列表与条数，不保留成功提示；失败时显示未删除数量和原因。

浏览器实测：1280×720 CSS px、DPR 2、100% 缩放、字体已加载；面板宽 480、内容宽 448、行高 66、主内容宽 404。字体为 Inter / macOS system / PingFang SC。
原生验证：1440×900 与 860×480 逻辑尺寸、Metal 截图倍率 2；面板宽 480、内容宽 448、行高 66。原生字体由应用全局主题提供，日期和内容使用隔离测试录制，按结构与尺寸比较，不对不同文字做像素相等断言。

实现使用仓库内 `vendor/zenit` 的 Zig 0.17 API、Button / Input / ScrollArea 与现有 control_hint；未使用 WebView。
