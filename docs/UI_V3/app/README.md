# ZeroWork 整机交互预览

> 当前评审：。本轮替代下文与其冲突的侧栏、会话、气泡、连接页与 KVM 展示规则；待用户确认后再落地 APP UI。
入口：[启动整机预览](index.html)。通过现有本地静态服务访问，不能以file协议代替同源消息路由。

这是单个浏览器页面中的整机HTML预览，不是正式APP。复用各模块可编辑HTML，在同源常驻HTML文档宿主中保留各自模型；宿主负责模块路由、设置浮层、全局主题、通知和传输任务。object文档宿主是原型复用方式，原生Zenit实施仍使用原生组件与应用状态路由，不引入WebView。

## 操作

- 标题栏右上功能区的四格图标打开“模块导航”。可进入终端与文件、主机连接、笔记、BMC iKVM，或打开设置和全局传输。导航支持方向键、Tab、Esc。
- 终端保留自己的会话页签、内置命令、会话组、广播、转发、历史与AI浮窗。模块切换不会重建已打开工作区。
- 连接管理的新建/保存/连接、已有主机更多菜单、新页签/窗口入口路由到整机内对应模块。新建SSH/SFTP向现有工作区追加独立会话；KVM按目标创建独立页面实例，导航中保留回访入口；VNC/RDP/FTP只在未来设计页独立评审，整机路由不接入。仅保存配置不打开会话。配置快照不包含秘密。
- 设置从齿轮、导航或⌘,打开，在原工作区上方显示；关闭受现有未保存确认控制，关闭后回原工作区。主题与所有已打开模块同步。
- 全局传输聚合各SFTP会话的实际模拟任务；暂停/继续/重试/取消发回原任务模型，“查看来源”回到来源模块。切换模块不转移任务所有权。
- 笔记与终端之间的命令准备、片段转存和上下文链接在整机内路由；已打开笔记实例保留草稿。AI仍属于具体工作区或协议会话，收起/停止交互沿用原模块。
- 全局通知投影到宿主右上角，保留来源模块；关闭通知不取消任务。

## 几何与实施

外部评审工具提供1440×900、860×480、适应当前窗口和十二主题。APP内部不显示分模块评审工具。原有标题栏、224↔48侧栏、32底栏和浮层边界仍以V3定义为基准。设置面板独立夹取可用空间。

状态仅在本次页面生命周期保留；刷新重建演示会话，设置仍遵循既有本地存储。HTML不建立真实网络、发起真实AI调用、访问凭据或操作文件/主机电源。全局任务投影通过消息读取源模型，不以第二份队列驱动模拟进度。

必要原生映射：WindowController/Router保存模块实例、WorkspaceModel持有SessionHandle、NotificationHost消费原operation、TransferManager按owner聚合；Modal使用框架焦点与恢复机制。详见[Zenit落地核查](../ZENIT_READINESS.md)。

## 本轮管理面板边界

连接管理和笔记现在打开独立工具浮层，不再替换中央连接内容页。管理面板采用同一模块源，父层负责标题/关闭与遮罩，适配器隐藏模块重复顶栏；完整独立模块仍保持原设计。关闭浮层回到原连接和未执行草稿。设置保持既有面板。终端、SFTP和KVM仍是连接会话。
