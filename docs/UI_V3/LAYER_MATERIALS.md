# 图层透明度与浮层设计记录

记录日期：2026-10-27。本文直接记录最终设计数值，原生实现与HTML基准使用相同参数。通用规则以[设计指南§3.3](../DESIGN/DESIGN_STANDARDS.md#33-阴影与背景能力)为准，实现入口为[app_theme.zig](../../src/ui/app_theme.zig)。

## 设计要求与术语

底层卡片更透明，上层浮窗、气泡更实；各层始终有自己的基础透明程度，不能全都依赖默认值为 0 的滑块才生效。只改变背景 RGBA，不降低文字、图标或整棵控件树的透明度。所有图层透出同一个窗口内背景，不重复绘制图片；本规则不表示窗口能透出 macOS 桌面。

本文的“透明度”均指透明程度 P，0% 为完全不透明、100% 为完全透明。代码 alpha 表示不透明度，方向相反：alpha=1−P。基础值取全局透明度滑块 0；已有滑块配置仍参与最终计算。

## 当前参数

工作区最终几何：外边距5pt，卡片间距8pt，顶栏36pt，底栏26pt，页签30pt。原生与HTML共用此组数值。

| 角色 | 用途 | 最终基础透明度 P0 | 滑块全程增量 D | 最大透明度 M |
| --- | --- | ---: | ---: | ---: |
| surface-1 | 主卡片、侧栏、顶栏、底栏 | 0.446777856 | 0.670166784 | 0.95 |
| surface-2 | 内部卡片 | 0.305690112 | 0.752467968 | 0.90 |
| well | 输入区、凹槽 | 0.211631616 | 0.728953344 | 0.80 |
| overlay | 浮窗、气泡、菜单 | 0.117573120 | 0.646652160 | 0.65 |
| hover | 悬停表面 | 0.235146240 | 0.646652160 | 0.75 |
| tab-on | 活跃页签 | 0.164602368 | 0.599622912 | 0.65 |

最终数值（全局滑块 T=0；alpha 表示不透明度，文字和图标不受影响）：

| 表面角色 | 最终基础透明程度 P（量化前） | 实际背景 alpha8 | 实际不透明度 |
| --- | ---: | ---: | ---: |
| surface-1 | 44.67778560% | 141/255 | 55.294118% |
| surface-2 | 30.56901120% | 177/255 | 69.411765% |
| well | 21.16316160% | 201/255 | 78.823529% |
| overlay | 11.75731200% | 225/255 | 88.235294% |
| hover | 23.51462400% | 195/255 | 76.470588% |
| tab-on | 16.46023680% | 213/255 | 83.529412% |

`T=clamp(background_transparency/100,0,1)`，`P=min(M,P0+D×T)`，`alpha8=round(255×(1−P))`。`P0`为代码直接使用的最终基础透明度，`D`为当前滑块全程增量，达到角色上限`M`后保持不变；不存在历史调节倍率。此表达保持当前滑块响应与各角色上限。

角色上限避免极端滑块值产生负 alpha，并保留上层可读底色。最终采用 8 位 alpha，表中未量化值与截图实际值存在约 0.2 个百分点以内的舍入差异。图片 alpha 仍为 1−T，与角色表面计算分开；图片关闭不关闭 UI 分层透明度。

浮层背景模糊为 max(12, blur_px) 逻辑 px。即使配置为 0，浮层仍有最低 12px，防止背景终端文字重影；根背景图使用用户配置的 blur_px，文字与控件自身不模糊。浮层采样已绘制的窗口内容，不采样桌面。

## 最终数值验收（2026-10-27）

外边距5pt、卡间8pt、顶栏36pt、底栏26pt、页签30pt，材质直接使用本文P0/D/M最终常量表。原生构建与材质专项测试通过；HTML合同验证12主题、4组T、3组B、有图/无图，共2304次角色alpha断言。隔离原生Harness在1440×900、860×480下确认标题卡分别为(5,5,1430,36)、(5,5,850,36)，并通过连接向导打开/关闭验证。
