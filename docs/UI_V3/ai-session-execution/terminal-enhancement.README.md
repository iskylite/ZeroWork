# 终端状态与命令历史原型（2026-10-31 同步）

本原型是本地 zsh、远程 SSH 终端的可编辑设计基准，演示数据不等于真实执行。命令历史、接管、逐命令装饰和显示设置的行为以本文及[会话执行设计](../../DESIGN/V0.2.6_AI_SESSION_EXECUTION.md)为准。自动会话初始化与「命令信息」是两个独立配置。

遵循 `docs/DESIGN/DESIGN_STANDARDS.md` §3.1–3.3、§4.1，以及 `LAYER_MATERIALS.md`。外边距5、卡片间距8、顶栏36、底栏26、主卡片圆角11；使用共享主题与字体。内容顶部不加信息栏，不添加容器描边或分隔细线。右下角复用现有 `terminal_styles.zig` 的「AI 控制 • 只读」和「接管」：右12、底10、高28、间距6。

## 入口

[可交互主原型](terminal-enhancement.html)默认展示 SSH，切页签查看本地 zsh；可在原型内核对默认、hover、历史与紧凑状态。

完整设置、连接原型同步添加相应字段，沿用原来的表单组件：`../settings/index.html?page=appearance` 与 `../connection/index.html?protocol=ssh`。主原型齿轮、主机行右键提供这一设置项的局部交互演示，用于核对生效规则，不意味着把正式设置改成独立小弹窗。

## 命令信息与复制

1. 状态图标在独立 gutter 中，与时间列同属界面绘制层。终端正文仍为14/22等宽字；左侧状态和时间不进入正文、复制或搜索。
2. AI、返回码、运行时间固定在命令**第一条视觉行的右边缘**，不重复到续行。用 `AI  ✓ 0  1.2 s`、`× 1  46 ms`；仅 AI 来源显示 `AI`。运行中保留 `AI — 耗时`（人工命令不带 `AI`），没有数字退出码；`—` 只表示尚未收到退出事件，不代表退出结果。不显示中文「退出」。
   首行 `AI` 使用轻量圆角tag：高16、左右内边距4、圆角4、等宽10/14、字重500，使用主题的 `popup-selected` 底色与 `accent-ink` 前景；在22px命令行内居中。AI信息组间距6，普通信息组保持10，以抵消tag内边距增加的宽度。历史卡片内的既有AI标记保持原样。
3. 右侧信息是独立覆盖层，不插入 VT 字符，不给长命令加省略号，不改变终端列数。长命令仍按原网格换行；鼠标移入该命令任一续行时，整组标记立即隐藏，完整露出下面文字；移出恢复。选择正文时也隐藏标记。隐藏只改可见性，不改变命令长度、布局或滚动位置。
4. 普通选区复制与菜单复制均只读取原始正文。HTML 演示除了 `user-select:none`，还将 copy Range 限定到 `#terminal-text`；原生沿用 VT selection/clipboard 数据路径，装饰层不写回网格。
5. 全局「命令信息」默认显示；SSH 主机为「继承全局 / 显示 / 隐藏」。本地 zsh 用全局值，SSH 用 `host override ?? global`。保存后实时更新已打开的相应会话。该开关只控制右侧信息组，不改变执行、记录、时间戳开关或左侧状态语义。

## 命令历史浮窗

- 浮窗固定在终端内容区右下，标准宽336，右/下边距12；每条命令为独立浅卡片，圆角8、卡间距8、内部10，运行中的记录使用轻量选中底色，列表内部滚动；不添加细线，不占布局列，不改变终端宽度或触发重排。历史项点击只定位原输出。
- 底栏最右侧使用「列表＋时钟」图标，与最左侧「侧栏」图标区分。按钮、中键菜单和 `@history on` 支持常驻打开；底栏按钮和 `⇧⌘B` 再次触发切换关闭。
- 常驻打开不随鼠标移开消失；×、按钮/快捷键切换、菜单「隐藏命令历史」或 `@history off` 明确关闭。
- hover底栏历史按钮触发临时预览，移入浮窗继续显示；移出按钮及浮窗后隐藏。选择/拖动正文期间不触发。临时预览点击历史项后转为常驻；点击 × 后不会因指针仍在附近立即重开。
- `@history` 的原生入口已注册；现有 `@log` 的会话记录回看语义保留。逐次命令历史不再以补全候选去重列表替代；每次执行单独记录并随终端记录保存，历史条目仅定位不执行。
- 终端右边缘不触发预览。底栏按钮与浮窗之间保留可移入路径；浮窗高度受卡片内容区约束，紧凑窗口使用内部滚动。
