# 全局主题背景与半透明表面

应用根部只绘制一次主题基色与可选图片。所有普通组件、卡片、内容容器和浮层透出这一层，按全局T派生半透明底色区分层次，不强制所有容器alpha0；T0保留基础透明层级，T增大时继续按角色派生。表面透明规则始终启用，与背景图片开关无关。

## 唯一全局派生公式

最终外壳几何为：外边距5pt、卡片间距8pt、顶栏36pt、底栏26pt、页签30pt。

当前合同以[设计指南§3.3](../DESIGN/DESIGN_STANDARDS.md#33-阴影与背景能力)、[图层材质记录](LAYER_MATERIALS.md)与 `src/ui/app_theme.zig` 为准。`T=clamp(background_transparency/100,0,1)`，`B=clamp(blur_px,0,96)`；真实产品默认T=0/B=0，不改配置默认值、不新增产品配置。T是滑块归一化值，不是每个表面的最终透明程度。

| 角色 | 用途 | 最终基础透明度 P0 | 滑块全程增量 D | 最大透明度 M |
| --- | --- | ---: | ---: | ---: |
| surface-1 | 主卡片、侧栏、顶栏、底栏 | 0.446777856 | 0.670166784 | 0.95 |
| surface-2 | 内部卡片 | 0.305690112 | 0.752467968 | 0.90 |
| well | 输入区、凹槽 | 0.211631616 | 0.728953344 | 0.80 |
| overlay | 浮窗、气泡、菜单 | 0.117573120 | 0.646652160 | 0.65 |
| hover | 悬停表面 | 0.235146240 | 0.646652160 | 0.75 |
| tab-on | 活跃页签 | 0.164602368 | 0.599622912 | 0.65 |

最终数值（全局滑块 T=0；alpha 表示不透明度，文字和图标不受影响）：

| 表面角色 | 最终基础透明程度 P（量化前） | 实际背景 alpha8 | 实际不透明度 |
| --- | ---: | ---: | ---: |
| surface-1 | 44.67778560% | 141/255 | 55.294118% |
| surface-2 | 30.56901120% | 177/255 | 69.411765% |
| well | 21.16316160% | 201/255 | 78.823529% |
| overlay | 11.75731200% | 225/255 | 88.235294% |
| hover | 23.51462400% | 195/255 | 76.470588% |
| tab-on | 16.46023680% | 213/255 | 83.529412% |

`T=clamp(background_transparency/100,0,1)`，`P=min(M,P0+D×T)`，`alpha8=round(255×(1−P))`。`P0`为代码直接使用的最终基础透明度，`D`为当前滑块全程增量，达到角色上限`M`后保持不变；不存在历史调节倍率。此表达保持当前滑块响应与各角色上限。HTML同样量化到8位，CSS使用 `alpha8/255`；card-deep复用surface-2、card-deep-ft复用well。overlay在T=1仍有35%不透明度，指令清单属于此角色。通知底栏使用统一surface-2，不单独覆盖alpha。

根背景图片alpha=`1−T`，根图blur=B；普通表面不另加模糊，临时浮层局部backdrop blur=`max(12,B)`。B0也保留12px，采样窗口内已绘制的内容，前景文字/图标不整树透明。图片开关只影响图片绘制，不关闭表面材质；浮层不复制图、不铺不透明地板、不采样桌面。

`shared/global-background.js`负责保存值、设置草稿事件和产品窗口外评审T/B的共同派生；通过已知同源文档宿主同步有效设置。嵌入模块不绘自己的背景图片；html根color-scheme随body同步，避免嵌入canvas在明暗切换时遮住根图。

`theme-tokens.css`保存12套基色与角色引用，使用公共服务写入的派生百分比；初始CSS后备值只是真实默认T=0的计算结果，不是独立固定alpha合同。`theme-presets.json`保存基色、锚点、透明上限和默认参数，示例有效RGBA仅用于核对默认公式。

`settings/app.js`仅新增既有background_transparency/blur_px/图片属性草稿watch→zw-material-draft事件；未改产品文案或其它设置业务。保存/撤销后的值走同一通道。根背景继续只绘一次，浮层不复制图、不铺地板。媒体图像/显式ANSI颜色属于真实内容，保留原色。

指令清单由renderPalette/renderOtherPalette共用positionPalette：锚定原会话输入框实际边界，在所属pane和应用可见区域交集内选择上下空间；宽≤520、高≤330，空间不足内部滚动，不覆盖输入行；滚动/resize重定位，原锚点不可见则关闭，不回落(0,0)。

## 验证入口

- 无图片：`app/index.html`。
- 连续性背景夹具：`app/index.html?background=continuity`。本地SVG只用于评审，图片不透明度为1−T；基色与图像只在根部合成，不是新增产品内置背景。
- 同页右上主题选择在dark/light间切换，再打开偏好设置、传输或AI气泡，检查根背景连续与浮层文字可读。

本HTML服务只读取可由浏览器使用的data:image/blob背景地址；本地文件路径读取、图片解码及实际配置持久化仍由原生负责人实现和验证，不能从浏览器夹具推定真实文件读取已通过。

当前有效设计规范的overlay alpha1/常驻壳实底/SSH菜单实底/SFTP双卡实底条文已被直接改写。凭据“不透明引用”、根基色不透明fallback及实际图像/ANSI内容语义保留，它们不属于旧的容器实底要求。
